# 使用指南的维护

系统内入口：`#/guide`，对已登录成员开放。页面顶部列出按角色分册、带截图的完整手册（飞书 CLAIN 知识库「七、正则使用手册」），下面是常用事项的简要步骤，每条注明详见哪本手册。

- 简要步骤：`web/src/guide.tsx`。
- 完整手册：正文源文件在 `docs/manual/`，每本一个 Markdown 文件；截图用 `scripts/demo/` 的演示环境（虚构数据）截取，不进仓库；修改后重新发布到知识库。

每次修改用户可见的入口、按钮、办理步骤、权限条件、截止规则或状态时，在同一个 PR 中：

1. 更新对应指南条目和 `docs/manual/` 里对应手册的章节，写清谁使用、从哪里进入、怎样办理、失败时找谁；界面变了的，重截相应截图。
2. 核对链接指向现有页面；不能把拟开发功能写成已上线。
3. 更新 `GUIDE_REVIEWED` 核对日期。页面系统版本自动读取构建版本，不另手填。
4. 验证手机上能搜索、展开条目并进入业务页；指南不提升任何权限。
5. PR 说明列出更新的指南条目和手册章节；没有用户流程变化时写明“不涉及指南更新”及原因。

指南不能替代章程或授权。规则有争议时核对当前制度与服务端实现；不凭手册描述修改权限。示例和截图只用虚构人员，不含名单、工资、合同、面试评价或密钥。

本次覆盖首次使用、双选、负责人加人、试做、日常研究、人员加入、身份/学期考核、支出资源、签到培训和问题反馈。相关 issue：#47、#52。
