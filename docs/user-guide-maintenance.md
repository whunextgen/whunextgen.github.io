# 使用指南的维护

系统内入口：`#/guide`，对已登录成员开放。内容唯一来源为 `web/src/guide.tsx`，不再维护另一份容易与页面不一致的完整手册。

每次修改用户可见的入口、按钮、办理步骤、权限条件、截止规则或状态时，在同一个 PR 中：

1. 更新对应指南条目，写清谁使用、从哪里进入、怎样办理、失败时找谁。
2. 核对链接指向现有页面；不能把拟开发功能写成已上线。
3. 更新 `GUIDE_REVIEWED` 核对日期。页面系统版本自动读取构建版本，不另手填。
4. 验证手机上能搜索、展开条目并进入业务页；指南不提升任何权限。
5. PR 说明列出更新的指南条目；没有用户流程变化时写明“不涉及指南更新”及原因。

指南不能替代章程或授权。规则有争议时核对当前制度与服务端实现；不凭手册描述修改权限。示例和截图只用虚构人员，不含名单、工资、合同、面试评价或密钥。

本次覆盖首次使用、双选、负责人加人、试做、日常研究、人员加入、身份/学期考核、支出资源、签到培训和问题反馈。相关 issue：#47、#52。
