# 新成员入门

- 适用范围：新加入的 Intern（RI）
- 负责岗位：中心助理
- 中台入口：https://clain-finance.pages.dev
- 最后整理日期：2026-11-26
- 截图来自演示环境，人名、课题和金额均为虚构。演示账号为陆一帆（Intern）。

加入中心即为 Intern（RI），不需要考核，也不做小任务。本手册列出加入后第一周要做的事，各功能的详细操作见《成员通用手册》（member.md）对应章节。

第一周清单：

1. 用飞书登录正则，确认人员档案已对应（第一节）。
2. 看懂「我的事项」，了解本人的主线任务（第二节）。
3. 签署协议和保密承诺，参加三项入门训练（第二节）。
4. 准备开题稿，在加入后第一期内交主线草稿的快照并在会上展示（第三节）。
5. 在双选中表达意向，申请回应一条质疑，争取进入一个研究单元（第四节）。
6. 按时签到，不能参加的事先请假（第五节）。

---

## 一、第一次登录

1. 打开 https://clain-finance.pages.dev ，点「飞书登录」，使用中心飞书账号授权。在飞书客户端内打开的，自动跳转授权。
2. 人事已为本人建档的，首次登录按姓名自动对应到档案，直接进入「我的事项」。

![登录页](img/intern/01-login.png)

3. 没有对应人员档案的，登录后显示「账号尚未启用」。中台已同时通知人事岗，待人事在人员档案中确认在岗或并入已有档案后，重新点「飞书登录」即可进入。

![账号尚未启用的提示](img/intern/02-wait.png)

注意：
- 请使用中心飞书账号登录，不要另建账号。
- 同名不止一人等情形不会自动对应，一律由人事确认。等待超过一个工作日的，联系人事岗。
- 登录后可点左下角「学术主页」填写本人谷歌学术主页链接，随姓名显示在课题列表和成员名单中。

## 二、看懂我的事项

「我的事项」是登录后的首页，各区块的用法见《成员通用手册》第一节。新成员先关注以下几处。

![Intern 的我的事项页首](img/intern/03-home.png)

1. 页首：身份显示为 Intern，红色区块显示本回合剩余天数、待办和主线进度。
2. 签到一栏：开会时签到、事先请假、会后补看回放（第五节）。
3. 当日三项日常：每天修订草稿后登记修订；每天审阅一份其他研究单元的快照并提交意见，意见被采纳的记入「利」。进入质疑队伍前，日常 02 显示「队里没有未回应的质疑」。
4. 任务列表与主线：黑底一行为当前主线步骤；右侧列出 Intern 的八步主线任务。

![任务列表和 Intern 主线八步](img/intern/04-tasks.png)

Intern 的主线任务如下，全部完成后可申请 RA 考核（小任务）：

| 步骤 | 任务 | 认定 |
|---|---|---|
| 01 | 签署协议和保密承诺，人员档案经人事确认 | 人事岗位 |
| 02 | 完成三项入门训练：集群使用（T101）、中台使用（T102）、科研规范与数据保密（T103） | 中台自动，按出勤 |
| 03 | 开题：加入后第一期内写出开题稿，在会上展示并接受质疑 | 会议记录 |
| 04 | 进入一个研究单元 | 中台自动，按研究单元名单 |
| 05 | 累计三期的快照里有本人回应的质疑（不要求连续） | 中台自动 |
| 06 | 综述一篇，在会上展示，下一期无人再提同样的质疑 | 会议记录 |
| 07 | 方案报告一篇，在会上展示，下一期无人再提同样的质疑 | 会议记录 |
| 08 | 作一次三分钟报告（主题研讨会或周日讲座） | 主题研讨会纪要 |

在「成长主线」页可查看每一步的说明和完成情况。

![成长主线：Intern 的任务清单](img/intern/05-path.png)

入门训练的开课和本人完成情况在「训练课程」页查看。上课时签到；请假的在一周内看完回放后计入。

![训练课程：面向 Intern 的三项入门训练](img/intern/09-courses.png)

## 三、加入后第一期内写开题稿

开题稿用理、据、体、用四问写清要研究的问题，作为本人主线上的草稿交快照，在主题研讨会上展示并接受质疑。

1. 准备好开题稿（飞书文档等可打开的链接）。
2. 左侧导航点「快照与质疑」，在「本人主线上的草稿」一节点「交主线草稿的快照」。
3. 选择挂在哪个课题之下（由该课题的负责人指导），成果填写「开题稿」，填写写作草稿的链接，可写本期改了什么，点「提交」。
4. 提交后该草稿出现在列表中，点同一行的「提交研讨会」，选择主题研讨会投稿，由组织者决定是否接收。
5. 在会上展示，会上提出的质疑记在这份草稿上。之后每两周修订一次再交快照，回应这些质疑同样记名义币。

![交本人主线草稿的快照对话框](img/intern/06-proposal-draft.png)

注意：
- 本期每个课题之下只有一份主线草稿快照，再交即更新；在会上讨论结束后不能再改。
- 只能投本期的快照；未被接收的，下一期重新提交。
- 开题由会议记录认定，认定后主线第 03 步显示已完成。
- 投稿研讨会和写质疑卡的办法见《成员通用手册》第三节。

## 四、进入研究单元

进入一个研究单元是 Intern 主线第 04 步，也是加入后两期内必须完成的事。有两条途径，可同时进行。

### 4.1 回应质疑，经负责人同意进入

1. 左侧导航点「快照与质疑」，在「未回应的质疑」一节浏览全中心公开的质疑，可按四问或研究单元筛选。
2. 找到感兴趣的质疑，点「申请入队」，写明说明提交。由该研究单元负责人加人（操作见《成员通用手册》3.4）。
3. 入队后把回应写进草稿，随下一次快照在会上展示。
4. 与负责人商定后，由负责人把本人加入研究单元名单。中台按名单判定主线第 04 步完成。

![未回应的质疑列表](img/intern/11-queries.png)

### 4.2 在双选中表达意向

1. 左侧导航点「双选」，在「可以参与的研究」一节阅读各课题和研究单元的介绍、最新快照和尚未回应的质疑。
2. 点「表达意向」，写明本人情况、对哪个方向感兴趣，可附作品链接，点「提交」。负责人收到通知；也可直接私聊负责人。
3. 谈妥后由负责人把本人加入成员名单，并可开一个月的试做期。试做期内要做的事和申诉办法见《成员通用手册》第四节。

![双选：可以参与的研究](img/intern/07-select.png)

![表达意向对话框](img/intern/08-interest.png)

注意：
- 入队和进入名单都由负责人办理，本人不能自行加入。
- 进入研究单元后，本人可在该研究单元提交快照、登记双周表（只在每期第一天登记，见《成员通用手册》第七节）。

## 五、签到与请假

周日讲座、主题研讨会、训练课程按出勤计入日常任务和入门训练。

1. 开会时在「我的事项」签到一栏点「签到」，输入会上共享屏幕上的四位签到码。线上参会的按飞书或 Zoom 参会名单自动签到。
2. 不能参加的，会前点「请假」，选择会议类别和日期提交。
3. 会后在签到一栏点「补看 ……」，看完回放后点「已看完回放」，计为出勤。

具体操作和截图见《成员通用手册》1.1 至 1.3。

注意：
- 请假须事先办理，日期不能早于当天；补看回放须在会后一周内登记。
- 周日讲座和主题研讨会的出勤按学期计，各不低于三分之二。

---

## 六、两期内不进研究单元会怎样

两周为一期。按成长路径第三节，加入满两期仍未进入任何研究单元的，办理离开。

1. 「加入与考核」页「新加入的成员」一节列出加入四个月内的 Intern、加入天数和所在研究单元，全体成员可见。
2. 加入满 28 天仍不在任何研究单元名单中（本人也不负责任何研究单元）的，该行标为「满两期未进研究单元」。
3. 中台同时通知本人和人事岗：本人收到提醒，可去回应某个研究单元的一条质疑、经负责人同意即可进入；人事岗据此办理离开，或确认本人已在研究单元中工作。

![新加入的成员：满两期未进研究单元的标记](img/intern/10-newcomers.png)

注意：
- 只入队回应质疑而未进入名单的，不算进入研究单元，须由负责人加入名单。
- 进入研究单元后，日常任务按期判定；连续两期不在任何研究单元里、快照里没有本人改动，或周日讲座无故缺席连续三次的，收回资源额度，再满两期仍未恢复的办理离开。
