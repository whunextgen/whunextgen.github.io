# 人事岗手册

- 适用范围：被授予人事岗角色的人员
- 负责岗位：人事劳务
- 中台入口：https://clain-finance.pages.dev
- 最后整理日期：2026-11-26
- 截图来自演示环境，人名、课题和金额均为虚构。演示账号为苏晴（人事劳务）。

人事岗在中台办理四类事项：人员档案（含新面孔登录后的确认）、加入申请的建档确认、人员经费的排布与发放、周日讲座和训练课程的出勤登记。人事岗本人作为成员的日常事项（签到、快照、支出申请等）见《成员通用手册》。

人事岗的入口分布如下：

- 左侧导航「系统」一组的「人员档案」；
- 第一组的「加入与考核」「训练课程」「快照与质疑」（出勤登记一节）、「成长主线」（须过问的情形一节）；
- 「财务 › 项目」一组的「人员经费」。

## 一、人员档案

人员档案每人一条，独立于账号：可以先登记档案，本人后登录。类别和状态以档案为准，账号上的身份随档案变化；档案登记为已离开的，对应账号随即停用。

1. 在左侧导航点「人员档案」。页首五个数字分别为在岗人数（另注非编人数）、待人事确认、账号没有档案、尚未登录、已离开。
2. 有待处理事项时，页面上方列出「待处理」表：标为「待确认」的是已用飞书登录、没有对应档案的人；标为「无档案」的是账号在用、尚未建档的人。
3. 下方「全部档案」按编号排列，可切换「在岗与非编」「已离开」「全部」，并按类别筛选。

![人员档案页：五项统计、待处理表和全部档案](img/hr/01-people.png)

### 1.1 新面孔登录后的确认

没有档案的人用飞书登录后不能直接进入中台，出现在「待处理」表中，状态为待确认。人事岗核实其为本中心人员后补全档案并确认，账号即可使用。

1. 在「待处理」表中找到此人，点「确认」。
2. 对话框中姓名取自飞书，可改为本名。依次填写编号、类别、状态、加入日期、学历、学校、研究方向、导师和备注。研究助理、研究实习生、硕士的编号可以留空，由中台自动顺延。
3. 核对无误后点「确认」。

![确认在岗对话框：补全档案后确认，账号随即启用](img/hr/02-confirm.png)

### 1.2 并入已有档案

此人已有档案（例如名单里登记过、加入申请建档时已建一条，但飞书上的名字不同）时，不再新建，而是把账号对到已有档案上。

1. 在「待处理」表中点此人一行的「并入」。
2. 在「已有档案（尚未对应账号的）」中选出那条档案，点「并入」。
3. 并入后账号对到所选档案，待确认的这一条删除。

![并入已有档案对话框：选出尚未对应账号的档案](img/hr/03-merge.png)

### 1.3 为在用账号补档案

「无档案」是账号已在使用、但没有人员档案的情况。

1. 在「待处理」表中点此人一行的「补档案」。
2. 已有对应档案的，在「对到已有档案」中选出即可，其余各项不必填写；没有的，按 1.1 的各项新建一条。
3. 点「保存」。

![补档案对话框：可对到已有档案，也可新建](img/hr/04-fill.png)

### 1.4 登记人员

尚未登录过中台的人也可以先建档，本人首次用飞书登录时按姓名对上。

1. 点页面右上角「登记人员」。
2. 填写姓名、编号、类别、状态、加入日期等，点「保存」。

![登记人员对话框](img/hr/05-add.png)

### 1.5 修改类别与状态、办理离开

类别分教师、博士后、博士、硕士、研究助理、研究实习生、访问学生、外部人员；状态分在岗、非编、已离开。

1. 在「全部档案」中找到此人，点「修改档案」。
2. 修改类别或状态。办理离开时，状态选「已离开」，填写离开日期（留空按当天）。
3. 点「保存」。登记为已离开后，对应账号随即停用；改回在岗或非编的，账号恢复启用。

![修改档案对话框：状态选已离开即办理离开](img/hr/06-edit.png)

4. 已离开的人员在「全部档案」切换到「已离开」查看，状态下方注明离开日期。

![全部档案切换到已离开](img/hr/07-left.png)

注意：

- 类别和状态以档案为准，不在「权限管理」里另改账号身份。
- 「待处理」中有档案可并入时才显示「并入」按钮。
- 学期考核中经中心负责人同意退组的，中台自动把档案记为已离开，无须人事另行办理。

## 二、加入申请的建档确认

加入中心即为 Intern（RI）。按章程，博士研究生、博士后、研究助理须在年度名额内推荐，经联席会议表决、中心负责人决定后由中台自动建档；硕士研究生、研究实习生（本科生）、访问学生由人事确认建档。

1. 成员提交硕士研究生、研究实习生或访问学生的推荐后，人事岗收到通知：加入待确认。
2. 在左侧导航点「加入与考核」，停留在「人员加入」页签。页面依次为年度名额、在办、新加入的成员、已办结。

![加入与考核：人员加入页签](img/hr/08-members.png)

3. 在「在办」中找到状态为「待人事确认」的申请，核对推荐理由和材料。
4. 同意的，点「确认建档」，可填写说明，点「建档」。中台建一条在岗档案，身份为 Intern（RI），加入日期为当天，并通知推荐人。
5. 不同意的，点「不予建档」，写明原因。原因通知推荐人。
6. 本人首次用飞书登录后，会出现在人员档案的「待处理」表中，按 1.2 并入这条档案。

推荐的入口和类别如下图（推荐由成员提交，人事岗不代为推荐）。

![推荐加入对话框：类别中标注了须联席会议表决的三类](img/hr/10-recommend.png)

博士研究生、博士后、研究助理经中心负责人决定接收的，中台自动建档，人事岗收到通知：新成员已建档，本人首次登录时请并入这条档案。此时人事岗只需在本人首次登录后按 1.2 并入。

注意：

- 「确认建档」「不予建档」按钮只在状态为「待人事确认」的申请上显示，须联席会议表决的三类不经人事确认。
- 演示环境中暂无待人事确认的申请，故未附确认对话框截图。

## 三、新人满两期未进研究单元的提醒

按成长路径第三节，加入满两期仍未进入任何研究单元的，办理离开。中台按天检查：Intern 加入满 28 天、既不负责也不在任何研究单元名单中的，通知人事岗，同时通知本人。

1. 收到提醒后，在「加入与考核」页「新加入的成员」表中查看。表中列出加入四个月内的 Intern，满两期仍未进入研究单元的标红，注明「满两期未进研究单元」。

![新加入的成员：满两期未进研究单元的标红](img/hr/09-newcomers.png)

2. 核实此人是否已在某个研究单元中工作（例如尚未被负责人加入名单）。已在工作的，请其所在研究单元负责人把本人加入成员名单。
3. 确实未进入的，按 1.5 把档案状态改为已离开。
4. 「成长主线」页「须过问的情形」一节另列出按章程第二十一至二十三条须过问的成员和研究单元（如周日讲座连续三次缺席未请假），由人事岗通知本人及其接收人。中台不自动下调身份。

![成长主线页：须过问的情形](img/hr/19-path.png)

注意：

- 同一人只提醒一次。
- 提醒只针对身份为 Intern、状态为在岗或非编、账号在用的人员。

## 四、人员经费

人员经费页按人员 × 月份排布每人每月的发放额及列支的经费卡，按月生成发放表、登记入账。财务侧的操作细节另见《财务岗手册》第十节。

1. 在左侧导航「财务 › 项目」下点「人员经费」。表中每格为当月发放额及列支的经费卡；红格表示发放日（当月 20 日）不在该经费卡有效期内，该笔无法发放，须变更经费卡。
2. 「检查」一节列出两项：列支于已回收、已结题或未下达经费卡的人月；本月尚未列入发放表的排布。

![人员经费：人员 × 月份排布](img/hr/11-staff.png)

### 4.1 排布

1. 点右上角「排布」。
2. 选人员、发放类型、起止月份、经费卡，填每月金额，点「保存排布」。金额留空表示撤销该段排布。

![排布人员费对话框](img/hr/12-plan.png)

### 4.2 生成发放表

1. 在「发放表」一节点「生成发放表」，选择月份，点「生成」。
2. 中台按发放类型和经费卡分表，只纳入发放日在经费卡有效期内的排布；列入发放表后，相应月份的排布锁定。

![生成发放表对话框](img/hr/13-build.png)

### 4.3 登记入账

1. 学校入账后，在发放表一行点「入账」。
2. 填写学校入账日期，点「确认入账」。入账后计入决算数。

![发放表入账对话框](img/hr/14-post.png)

### 4.4 人员与发放类型

页面底部「人员」一节可新增或修改人员名称，「发放类型」一节可新增或修改发放类型，发放类型决定该笔款项计入的科目，可设每人每月上限。

注意：

- 已列入发放表的月份不得修改排布。
- 变更经费卡须有变更权限，人事岗默认没有，请财务岗办理。

## 五、周日讲座的出勤

周日讲座由人事岗在正则上开会签到。出勤按学期计，不低于三分之二；在岗人员既未签到也未请假的记为缺席。

### 5.1 开会签到

1. 在左侧导航点「快照与质疑」，下拉到「出勤登记」一节。
2. 讲座开始时点「开周日讲座签到」，进入会议现场页。页面显示四位签到码（三小时内有效）、已签到和请假人数。把这一页共享到屏幕上，到会者在「我的事项」点「签到」输入签到码，线上线下同等计入。
3. 会议现场页可「填飞书会议」或「填 Zoom 会议」：飞书会议每 5 分钟同步一次参会名单，线上参会的自动签到；Zoom 会议散会后读参会报告，对不上的名字由开会人认领。
4. 讲座结束后点「散会」。签到码随即作废；事先请假的记为请假；在岗人员没有签到也没有请假的记为缺席。
5. 会后点「挂纪要链接」，填写飞书妙记或录屏链接。请假的人在一周内看完回放，本人在「我的事项」登记补看，计为出勤。

![快照与质疑页：出勤登记一节，开周日讲座签到和补登入口](img/hr/17-attendance.png)

### 5.2 补登出勤

未在正则上开会签到的讲座，可在会后一次登记。

1. 在「出勤登记」一节点「补登周日讲座出勤」。
2. 填写日期和题目，在名单中勾选出席和事先请假的人，点「登记」。

![补登周日讲座出勤对话框](img/hr/18-lecture-backfill.png)

注意：

- 同一类会有一场未散会的，不能再开一场。
- 出勤登记一节下方的表列出最近 12 次会的出席、请假、缺席人数和登记人，点会议名可进入该次会议页。

## 六、训练课程的出勤登记

训练课程按身份开设，自愿参加。Intern 的三项入门训练（T101、T102、T103）按出勤由中台自动认定，请假的在一周内看完回放后计入。训练课程的出勤由人事岗登记。

1. 在左侧导航点「训练课程」。课程按面向 Intern、Assistant、Researcher 分三组，列出已开次数和最近一次日期。

![训练课程页](img/hr/15-courses.png)

2. 在所开课程一行点「登记出勤」。
3. 填写日期（不晚于今天），在名单中勾选出席和事先请假的人，点「登记」。

![训练课程登记出勤对话框](img/hr/16-course-attend.png)

注意：

- 训练课程目前不经开会签到，只能会后登记。
- 登记出勤仅人事岗和中心负责人可办。

## 七、ARR 担保名额

人员档案页底部「ARR 担保名额」一节由人事岗维护：登记具备 ARR 审稿资格的担保人、每轮名额和本轮线下已占，开启新一轮。研究单元负责人在研究单元页上请担保人，提交申请即占用名额。

1. 点「登记担保人」，选人员、资格、每轮名额、本轮线下已占，备注仅人事岗可见，点「保存」。已登记的点「修改」。
2. ARR 进入新的截稿月份时，点「开启新一轮」，填写轮次名称。开启后各人余量按每轮名额重新起算，上一轮仍未答复的申请随之结束，并通知申请人和担保人。

![人员档案页：ARR 担保名额一节](img/hr/21-arr.png)

注意：

- 余量仅研究单元负责人、担保人本人和人事岗可见；备注和不合格人员仅人事岗可见。
- 取消资格后不能再被请，已同意的担保仍然有效。


## 核对双选名单

双选页底部的名单默认收起，点击标题旁「展开查看」后核对。这里提供当前在岗及非编 RA、RI、硕士的归属核对。普通成员只查看本人；有人员查看或管理权限的经办可以查看全员，并按人员类别、双选状态、姓名、课题或负责人筛选。已加入以当前有效课题/研究单元成员名单为准，意向不等于完成，历史退出、停用和待立项课题不计入。未关联或停用账号单列为待核对。统计不是本轮新增人数；线下谈妥后仍需负责人加人，点击「刷新双选情况」读取最新记录。
