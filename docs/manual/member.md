# 成员通用手册

- 适用范围：全体成员
- 负责岗位：中心助理
- 中台入口：https://clain-finance.pages.dev
- 最后整理日期：2026-11-28
- 截图来自演示环境，人名、课题和金额均为虚构。演示账号为许若溪（Assistant，负责研究单元）。

本手册按成员日常要办的事分节。左侧导航第一组（我的事项至任务管理）是每位成员都会用到的页面；「课题」一组中的支出申请、备用金管理、资源申领仅对已在某个已立项课题或研究单元名单中的成员显示。课题负责人、财务岗、人事岗的办理事项另见各岗位手册。

## 一、我的事项

登录后首先进入「我的事项」。本页集中显示本回合（两周一期）的日程、当日三项日常、属性、待办、本期登记、任务列表、本人的支出申请和备用金、份额与实际币、嘉许。顶部一排按钮可跳到各区块。

1. 页首显示本人身份、称号、所在研究单元和所属课题，右侧红色区块为本回合剩余天数、待办项数和主线进度。
2. 页首下方一栏为签到、请假、补看回放、自建会议的入口；有正在开的会时，另显示「正在开：……」链接，点击进入会议现场。

![我的事项页首：身份、本回合、签到一栏和当日日历](img/member/01-home.png)

### 1.1 签到

周日讲座、主题研讨会、联席会议、训练课程开会时，组织者在共享屏幕上显示四位签到码。

1. 在签到一栏点「签到」。
2. 对话框列出当前正在开的会，输入四位签到码，点「签到」。

![签到对话框：输入会上显示的四位签到码](img/member/02-signin.png)

线上参会的，组织者挂上飞书会议或 Zoom 会议后，中台按参会名单自动签到，不必另行输入签到码。

### 1.2 请假与补看回放

1. 不能参加的，会前点「请假」，选择会议类别（周日讲座、主题研讨会、联席会议、训练课程）和日期，可填写原因，点「请假」。
2. 会后组织者挂上飞书妙记或录屏链接。签到一栏出现「补看 月-日 会议名称」按钮，点开后打开回放，看完点「已看完回放」，计为出勤。

![请假对话框：选择会议类别和日期](img/member/03-leave.png)

### 1.3 自建会议

本人组织的小组会、读书会等也可在正则上开会，取得签到码、自动签到并在会后挂纪要。

1. 点「自建会议」，填写题目，点「开会」，进入会议现场页。
2. 现场页可填写飞书会议或 Zoom 会议、挂纪要链接；会议结束点「散会」。

![自建会议对话框](img/member/04-own-meeting.png)

注意：
- 请假须事先办理，日期不能早于当天。
- 补看回放须在会后一周内登记，逾期不能补登。
- 自建会议只作记录，不计入日常任务。本人开的自建会议须先散会，才能再开下一场。

### 1.4 当日三项日常

「当日」区块显示本回合十四天的日历（第 1 日开始，第 8 日半程，周日讲座，第 14 日快照），下方为每天的三项日常，每日 0 时更新。

![当日：本回合日历和三项日常](img/member/05-today.png)

1. 日常 01 修订：当天第一次修订写作草稿后，点「登记修订」，选择研究单元，推进了队伍中某条质疑的一并选上，点「登记」。记入「贞」，连续修订的显示连续天数。
2. 日常 02 推进：从本人所在质疑队伍的未回应质疑中当日抽取一条，当日有推进并修订草稿即完成。不在任何质疑队伍中的，显示「队里没有未回应的质疑」，可到「快照与质疑」申请入队（见第三节）。
3. 日常 03 审阅：从其他研究单元最近的快照中当日抽取一份。点「提交意见」，打开快照读其中一节，写下意见提交。意见被该研究单元负责人采纳的，记入「利」。

![登记当日修订对话框](img/member/06-revision.png)

注意：
- 修订只能登记本人所在研究单元或所在质疑队伍的稿子。
- 审阅意见不超过 500 字，只能审阅本人不在名单中的研究单元的快照。

### 1.5 属性、待办与本期登记

1. 属性区块显示八项属性：文章四项（理、据、体、用）按回应质疑所得的名义币累加；德行四项（元、亨、利、贞）按规定点数累加。属性只增不减。
2. 待办区块只列与本人有关的事项（被指派的任务、待申报的预算、双周表等），点右侧按钮直接办理。
3. 本期登记区块列出本人所在研究单元本期双周表的状态；登记日当天显示「登记」按钮，详见第七节。

![属性、待办和本期登记](img/member/07-attr-todo.png)

### 1.6 任务列表与主线

任务列表按类别分为主线、副本、本期、学期四类，可用上方标签筛选。

1. 主线：本人当前身份的下一步主线任务，点击进入「成长主线」。
2. 副本：本人所在质疑队伍中尚未回应的质疑。下一期会上无人再提即为已回应，记 16 名义币，由队员平分，进入研究单元的池子。
3. 本期：主题研讨会、周日讲座出勤，快照里有本人的改动，负责研究单元的登记双周表并展示快照。
4. 学期：本学期的挑战，例如四问各回应质疑一条、向三个不同研究单元提出质疑等，显示进度和对应的属性或称号。
5. 右侧为主线步骤一览和连续全勤期数。本期任务全部完成即为全勤一期，连续全勤的「贞」多计（每期加 10%），中断即清零，已有属性不受影响。

![任务列表和主线步骤](img/member/08-tasklist.png)

### 1.7 支出申请、备用金和资源申领区块

「本人的支出申请」列出本人提交的在办申请及所处环节；「本人的备用金和资源申领」列出在办的备用金和资源申领。区块内的「提交支出申请」「申领资源」「申请备用金」与对应页面功能相同，办理方法见第十至十二节。

### 1.8 份额与实际币

![支出申请和备用金区块，以及份额、实际币、嘉许](img/member/09-share-coin.png)

1. 「我在各研究单元的份额」：本人回应质疑所得的名义币进入研究单元的池子，此处显示本人在各池子中的名义币和占比。池子在研究单元取得第一个外部成果时解锁，按挂牌铸造率铸造实际币到个人。
2. 「实际币」：显示余额、两个月内到期数、卡时标价和最近的收支。实际币主要靠在正则上做事得到：组织研讨会、提质疑、到场签到、写快照点评、登记双周表和日常、联席会议提案和表决、带试做期、训练课程等，每完成一件自动发到个人账上，连续做还有奖励；展开「做任务换币」可看每类行为发多少、本季度已得多少（每人每季度最多 3,000）。按期发放的只是很少一部分。余额大于 0 时出现「投给研究单元」按钮，选择研究单元和数目投入，由研究单元负责人换 GPU 卡时或 API 额度。API 额度计入这个研究单元的 key，名单内成员共用，在研究单元页取用（见第十二节）。

注意：
- 代币不是经费，不能用于支出申请。
- 按期发放的和做任务得的实际币当季有效，季末（1、4、7、10 月最后一天）作废；成果铸造的 12 个月有效；投出时先扣先到期的。投给研究单元的沿用原来的到期日。
- 实际币只能投给已成立的研究单元，投给哪一个不限。

### 1.9 嘉许

每期可嘉许同伴两次，记入对方元（指导）、亨（展示）、利（协助）、贞（守时）中的一项。

1. 在嘉许区块点「嘉许一位同伴」。
2. 选择嘉许谁、记入哪一项，可写明原因，点「嘉许」。

![嘉许对话框](img/member/10-praise.png)

注意：不能嘉许本人；原因不超过 120 字；每期两次用完后按钮不再显示。

页面最下方为各期记录（讲座、研讨会、双周表、快照收录，斜线为请假补看）和称号一览。称号按记录取得，不收回。

## 二、成长主线

身份分 Intern（RI）、Assistant（RA）、Researcher、Rising Star、PI、Director 六种，靠完成本级的全部主线任务并通过考核取得。

1. 左侧导航点「成长主线」，「本人」一节列出当前身份的主线任务、认定方和状态。认定方为中台自动的按记录判定，其余由对应岗位或联席会议确认。
2. 认定方为联席会议的任务（如完成一篇完整的研究论文），点「提交联席会议审核」，填写材料链接和说明。正则将其列入联席会议议程（免附议、不记名），决议生效即认定完成。
3. 下方依次为属性、各期日常任务的完成情况和考核。

![成长主线：本人的主线任务清单](img/member/11-path.png)

4. 本级任务全部完成后，在「考核」一节点「申请 RA 考核」（Intern）或「申请 Researcher 考核」（Assistant），按对话框说明提交。未完成时按钮不可用。

![日常任务和考核一节](img/member/12-path-assess.png)

注意：
- 申请考核时，本级主线任务须全部完成，申请当期的本期任务也须已完成。
- RA 考核为小任务：两名 Researcher 布置，为期两周，两人一致认定通过即为 RA。Researcher 考核为课题提案及联席会议答辩，表决后由 Director 认可。
- Assistant 的「接收过至少一名 RI，并带其通过 RA 考核」由中台自动判定：「接收」指这名 RI 最早进入的研究单元由你担任负责人（由你或副手在研究单元页「成员」一节加入名单，或加入质疑小队进入名单）。此人通过 RA 考核时，当时该研究单元的负责人记为带出此人的人，这一步即完成。给研究单元加人的是该研究单元的负责人和副手，所以这一步要在担任研究单元负责人（主线第一步）之后才能做到。
- 身份认定由中心负责人办理，升降都记录依据并通知本人。

## 三、快照与质疑

每两周一期，研究单元交一次快照（当期写作草稿的样子），提交给主题研讨会；会上提出的质疑逐条记入，每条指明针对理、据、体、用中的哪一问。未回应的质疑全中心公开，组队回应。

![快照与质疑：本期快照一节](img/member/13-iterate.png)

### 3.1 提交快照

本人负责或在名单中的研究单元都可提交。

1. 在「本期快照」一节找到研究单元，点「提交快照」。
2. 填写写作草稿的链接，可写本期改了什么，勾选本期在草稿里有改动的成员，点「提交」。本期已交的，按钮变为「更新快照」。

![提交本期快照对话框](img/member/14-snapshot.png)

本人主线上的草稿（开题稿、综述、方案报告、立场论文等）在「本人主线上的草稿」一节点「交主线草稿的快照」，挂在一个已立项课题之下，办法相同，详见《新成员（Intern）入门》第三节。

### 3.2 投稿研讨会

1. 本期快照提交后，同一行出现「提交研讨会」按钮。
2. 选择一个或多个主题研讨会（认知基础、医疗、金融、人文社会），点「提交」。
3. 由所投研讨会的组织者决定接收为口头报告、海报或不接收，状态显示在「研讨会」一列。组织者点错的，本期内可以撤回，改回投稿待定后重新决定，届时会收到通知。

注意：
- 只能投本期的快照；未被接收的，下一期可重新提交。
- 本期快照在研讨会上讨论结束后不能再修改。
- 勾选的有改动成员须在研究单元名单中，日常任务「快照里有本人的改动」按此判定。

### 3.3 写质疑卡

研讨会上讨论某份快照时，每位与会者可在自己的手机或电脑上写质疑卡；会前也可在研讨会页提前写。

1. 会前：在「主题研讨会」一节点研讨会名称，进入研讨会页，在已接收的快照一行点「写质疑卡」。
2. 先打开草稿阅读，选择针对哪一问，写下质疑，点「交卡」。
3. 会上：在会议现场页「写质疑卡」处写下质疑，点「提理」「提据」「提体」「提用」之一提交。
4. 组织者核对记入后，质疑计在提出人名下，记入「利」。

![研讨会页上的写质疑卡对话框](img/member/17-card.png)

### 3.4 申请入队回应质疑

1. 在「未回应的质疑」一节，可按四问或研究单元筛选。
2. 找到要回应的质疑，点「申请入队」，可写说明，点「申请」。正则通知该研究单元负责人。
3. 负责人加人后，本人即在队伍中，此后该质疑出现在「我的事项」的副本和日常 02 中。
4. 把回应写进草稿，随下一次快照在会上展示；下一期会上无人再提的即为已回应，16 名义币由队员平分。

![未回应的质疑列表](img/member/15-queries.png)

![申请入队对话框](img/member/16-join-query.png)

注意：
- 入队由研究单元负责人加人，本人不能自行加入。
- 新入队的自下一期起参与分配，入队当期的名义币仍由原有队员平分。
- 入队回应其他研究单元质疑的，不因此进入该研究单元名单；进入名单由负责人办理（Intern 进入研究单元的办法见《新成员（Intern）入门》第四节）。

## 四、双选

Intern、Assistant 和硕士研究生在此选择参与的课题和研究单元。

![双选：我的试做、可以参与的研究](img/member/18-select.png)

### 4.1 表达意向

1. 在「可以参与的研究」一节阅读课题和研究单元的介绍、最新快照和尚未回应的质疑。勾选「只看有待回应质疑的」可缩小范围。
2. 点「表达意向」，写明本人情况和感兴趣的方向，可附研究兴趣或作品链接，点「提交」。负责人收到通知。
3. 也可直接私聊负责人。谈妥后由负责人在正则上把本人加入成员名单，并可同时开一个月的试做期。
4. 已表达的意向列在「我的意向」中，可撤回。

### 4.2 试做期内要做的事

试做期开始后，「我的试做」一节显示课题或研究单元、指导人、试做期限和首个小任务。

1. 按要求完成首个小任务，期间点「提交阶段进展」，写明已完成什么、遇到什么困难、下一步，可附链接。
2. 指导人给出阶段反馈后，显示在同一卡片中。
3. 期满前点「提交期满交付」，写明交付物说明和简短自述。
4. 指导人给出期满结论（继续参与、延长试做、调整安排、结束本课题参与），报联席会议备案。

### 4.3 申诉

结论为结束本课题参与的，本人可向联席会议申诉。

1. 在「我的试做」卡片上点「向联席会议申诉」，写明申诉理由，点「提交」。
2. 正则将申诉列入联席会议议程（免附议、不记名），本人可到会陈述；表决通过的恢复成员资格。卡片上显示「申诉议题」链接。

注意：
- 试做期一个月，可延长一次，延长不超过一个月；已在名单中的成员不重新试做。
- 考察标准按身份：Intern 和硕士研究生看研究热情和投入；Assistant 另看研究能力。均不以发表为标准。
- 结论只影响该课题或研究单元的成员资格，不影响身份。
- 申诉须在结论作出后七日内提出。

## 五、联席会议

联席会议由有表决权的成员（Researcher、Rising Star、PI）组成，Assistant 和 Intern 推选的学期代表列席，有发言权、无表决权。Director 不参加，可在决议通过后三个工作日内否决。

![联席会议：议题按状态分组列出](img/member/19-council.png)

### 5.1 成员能看什么

1. 全体成员可查看全部议题，按表决中、待附议、待表决或过问、否决期内、已生效、未通过等状态分组；点议题进入议题页，查看提案全文、表决规则、结果和记名表决的票。
2. 页面下方依次为中心负责人特批记录、试做期结论备案和学期代表。
3. 本人提交的研究单元申请、考核申请、主线任务审核、试做申诉等，由正则自动列入议程，在此跟踪进度。

### 5.2 推选学期代表

1. 在「学期代表」一节点「推选代表」，选择一位 Assistant 或 Intern，点「投票」。
2. 得票最多者当选。已投票的按钮变为「改票」，可随时改投。

![推选代表对话框](img/member/20-rep.png)

当选代表可提交提案、在会议现场申请发言，但不参加表决。

### 5.3 附议与表决（有表决权的成员）

有表决权的成员在议题页附议、申报回避、提修正案或复议；会上表决在会议现场页进行，紧急议题可会外表决。具体办法见《课题负责人手册》。

## 六、加入与考核

本页分「人员加入」和「学期考核」两个标签。

### 6.1 推荐新人

在册成员均可推荐。

1. 在「人员加入」标签点「推荐加入」。
2. 填写姓名、类别，可填学校或单位、研究方向，写明推荐理由（研究兴趣、已有工作、拟参与的课题或研究单元），可附主页或简历链接，点「提交」。
3. 博士研究生、博士后、研究助理：正则列入联席会议议程表决，决议生效后由中心负责人决定。硕士研究生、研究实习生、访问学生：由人事确认建档。
4. 办理进度显示在「在办」一节，未办结前推荐人可撤回。

![推荐加入对话框](img/member/21-recommend.png)

注意：
- 博士研究生、博士后、研究助理须在中心负责人确定的年度名额内推荐；名额未确定或已满的不能提交。
- 同一人已有在办申请或已在人员档案中的，不能重复推荐。
- 与被推荐人有私人关系的，在联席会议表决时申报回避。

### 6.2 查看本人考核

联席会议每学期组织一次成员考核，依据双周表、成长主线、研究单元名单、支出和出勤记录以及合作者匿名短评，不另写总结。

1. 点「学期考核」标签。「我的考核」一节显示考核人、状态、本学期记录汇总、考核意见和改进目标。
2. 结论分正常、需改进、建议退组。需改进的，与考核人商定约两个月的改进目标，到期由考核人记录是否达成。

![学期考核：我的考核、待我办理](img/member/22-term.png)

### 6.3 写匿名短评

与被考核人同在一个课题或研究单元的合作者，可为其写短评。

1. 「待我办理」一节列出可写短评的考核，点「写匿名短评」。
2. 写具体的事，三百字以内，点「提交」。考核意见出具之前可点「修改短评」。

![匿名短评对话框](img/member/23-comment.png)

### 6.4 书面申辩

考核结论为需改进或建议退组、已列入联席会议议程的，本人在「我的考核」中点「书面申辩」，写明申辩内容提交。申辩附在联席会议议题后，也可在议题页申请到会陈述。

注意：
- 短评只给考核人和联席会议主持人看，不显示作者；不能给本人写，考核人不另写短评。
- 书面申辩只有一次，不超过 3000 字，须在表决结束前提交。
- Intern、Assistant 由合作的 Researcher 及以上成员评价，报联席会议备案；建议退组的须联席会议三分之二同意、中心负责人决定。

## 七、双周表

每个研究单元每两周登记一次双周表，研究单元的负责人和名单中的成员都可以登记（同一期只有一份，后登记的覆盖先登记的）。

1. 左侧导航点「双周表」。「我的研究单元」一节列出本人所在的研究单元及本期状态。
2. 登记日当天显示表单：选择写作进度（想法、摘要、首图、核心结果表、完整初稿、投稿稿），填写本轮回答的问题、已完成的工作与阶段结果、本轮改变的判断、遇到的问题（选填）、成员分工、下一轮安排与预期，点「登记」。
3. 「全部研究单元」一节按课题列出各研究单元的登记情况，点名称查看历次登记。

![双周表：我的研究单元和全部研究单元](img/member/24-biweekly.png)

注意：
- 双周表只在每期第一天（登记日）登记，交上一期的结果和这一期的计划，当天 24:00 截止，不补登。
- 一期未登记的研究单元由联席会议优先过问；连续两期未登记的转为停滞，负责人须到联席会议说明。
- 在登记日以外登记，须经中心负责人特批，特批记录在联席会议页公开。

## 十、支出申请

先申请、后支出。研究单元使用所属课题的预算，申请按课题的预算行提交。

1. 左侧导航「课题」组点「支出申请」，点「提交支出申请」，页面上方展开表单。
2. 选择课题、预算行、支出类型，填写事项、金额、预计学校入账日，选择采购路径（不涉及采购、直采、集采、分散采购）。
3. 点「提交申请」。
4. 下方列表显示本人的申请及所处环节。状态下方四格对应申请、确认、提交学校、入账四个环节，金色为所在环节。

![支出申请：提交表单和申请列表](img/member/27-new-request.png)

注意：
- 仅可在本人所属成员名单的课题或研究单元内提交；课题列表只列出本年度有可用预算行的课题。
- 提交后先由研究单元负责人确认，再由财务岗核对；超出预算行的不拦截，标明超出金额，另由中心负责人审批。
- 最终列支的经费卡由财务岗安排，申请人无需选择。
- 支出前先到「报销咨询」查询该类支出可否报销（见第十三节）。

## 十一、备用金

用于来不及办理支出申请的小额周转，同样从年度预算列支。

- 核销时实际支出部分须对应同一预算行上一笔已批准的支出申请，须先在「支出申请」中登记。

## 十二、资源申领

接口额度从中心已充值的额度里分配，不动经费卡，计入所选课题的预算行；设备和耗材按年度预算里的资源计划申领。

1. 「课题」组点「资源申领」。页首显示本人名下接口额度、资产、在途申请和即将到期的数目。
2. 点「申请接口额度」或「申领资产」。接口额度选计入的预算行（本课题任一已下达的预算行都可以；没有资源计划的，再选接口资源）；资产选已编制资源计划的预算行。填写额度或数量、使用月份、用途，需要加急的勾选「加急」并写明用量估算，点「提交申请」。
3. 研究单元负责人批示后，由财务岗批准并分发。本人负责的研究单元直接提交财务岗。
4. 分发后在「本人名下资源」中查看；接口密钥加密保存在中台，可在此自行取用，每次取用均有记录。
5. 研究单元负责人用单元账上的实际币换得的 API 额度不经这里申请，也不发到个人名下：额度计入这个研究单元的 key，名单内成员在研究单元页「池子与成果 › 实际币」下的「API key」一栏点「取用 key」，每次取用均有记录。移出名单后不能再取用，财务岗会更换 key，旧 key 作废。

![资源申领：本人名下资源和申请记录](img/member/29-resource.png)

注意：
- 接口额度：预算行没有资源计划或计划不够的也可以申请，申请上注明「批准时追加」，由财务岗批准时追加资源计划；本行支出加额度申请不得超过核定数。
- 资产：累计申领不得超过预算行的计划数量；预算中没有资源计划的不能提交，须由研究单元负责人在年度预算中补充。
- 接口账户由财务岗统一充值，课题不在「支出申请」里提交 API 充值这类支出；使用接口额度一律在本页申请，计入课题预算、不动经费卡。
- 申请中不得填写任何密钥。
- 公共设备仅面向博士后、博士、硕士和研究助理，且须已在某个已立项课题或研究单元的名单内。
- 额度到期或收回后密钥随之撤销。

## 十三、报销咨询

支出前先查询该类支出可否报销。结论来自学校财务的答复，由财务岗登记。

1. 「课题」组点「报销咨询」，按支出类型查看结论（可报销、有条件报销、有争议、不可报销、尚未咨询）、说明和最近答复日期。
2. 可报销的，到「支出申请」从研究单元预算行提交。
3. 未查到、尚未咨询或有争议的，先咨询财务岗再支出。

## 十四、智能体接入（访问令牌）

中台的视图和操作经 MCP 接口开放。为本人的智能体建一个访问令牌，它即可以本人身份查数据、办业务，各项权限和业务检查照常生效。

1. 左侧导航「系统」组点「智能体接入」，点「新建访问令牌」。
2. 填写用途（例如本人的 Claude），选择权限（只读或可写）和有效期（30 天、90 天、一年），点「生成」。
3. 令牌只在生成后显示一次，当场复制保存。
4. 按页面「接入方法」把接口地址和令牌配置到智能体中。接口提供 whoami、list_views、read_view、list_actions、call_action 五个工具。
5. 不再使用的令牌在「本人的令牌」中点「停用」，停用后立即失效，不可恢复。

![新建访问令牌对话框](img/member/31-agent.png)

注意：
- 每人最多同时持有 5 个有效令牌。
- 可写令牌会改动数据，只交给可信的智能体；令牌丢失的停用重建。
- 经令牌办理的业务（成功和失败）都记入「操作记录」；查数据不记。
- 密钥的保存和取用不经此接口开放。

## 核对双选名单

双选页底部的名单默认收起，点击标题旁「展开查看」后核对。这里提供当前在岗及非编 Intern、Assistant 或硕士研究生（以人员档案的中心身份为准，硕士研究生不限身份）的归属核对。普通成员只查看本人；有人员查看或管理权限的经办可以查看全员，并按中心身份 / 硕士标注、双选状态、姓名、课题或负责人筛选。已加入以当前有效课题/研究单元成员名单为准，意向不等于完成，历史退出、停用和待立项课题不计入。未关联或停用账号单列为待核对。统计不是本轮新增人数；线下谈妥后仍需负责人加人，点击「刷新双选情况」读取最新记录。


## 课题与研究单元人数口径

双选页和课题管理列表中，课题人数为直属成员与下属有效研究单元成员的并集，按账号去重，同一人加入多个研究单元或同时在直属名单中只计一次。研究单元仍只统计本单元。仅计启用账号且加入日期已生效、尚未退出的成员；已停用、待立项和公共项目不纳入研究汇总。课题旁同时注明直属人数。负责人仅在实际有成员记录时计入，不另加一人。

课题详情的「直属成员」维护的仍是原直属名单。人数汇总不创建父课题成员关系，不改变预算、支出、资源、份额或审批权限。真实名单直接从中台读取，无需重新导入。
