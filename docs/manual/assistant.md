# 中心助理手册

- 适用范围：被授予中心助理角色的人员
- 负责岗位：中心助理（联席会议主持和日常运营）
- 中台入口：https://clain-finance.pages.dev
- 最后整理日期：2026-11-26
- 截图来自演示环境，人名、课题和金额均为虚构。演示账号为沈可（中心助理）。

中心助理是联席会议的主持人，在中台办理：联席会议的议程、开会、表决和过问；联席会议的签到与散会；学期成员考核的发起和进展小组登记；研究单元申请的核对成立；任务管理。中心助理本人作为成员的日常事项见《成员通用手册》。

中台按权限识别主持人：持有中心助理角色（评定录入权限）的账号和中心负责人账号均可主持联席会议。中心助理本人不在有表决权的成员之列的，不能提案、附议和投票。

---

## 一、联席会议议程

议题从提案、附议、讨论、表决到否决期和生效，全在中台办理。研究单元申请、课题立项与延续、预算调整、考核、成长主线审核、人员推荐等，在各自的申请里提交，由正则自动列入议程（免附议）；研究单元连续两期未登记双周表的，由正则自动列入过问。其他事项由有表决权的成员、中心负责人或本学期代表在联席会议页提案，须经另一名有表决权的成员附议才列入议程。

1. 在左侧导航点「联席会议」。页首注明有表决权的成员人数、本学期代表。
2. 议题按状态分组：表决中、待附议、已列入议程（待表决或过问）、已通过（否决期内）、已生效、未通过被否决已撤回。每行注明类别、提案人（自动列入的注明「申请自动列入」）、表决规则和状态。

![联席会议页：议题按状态分组](img/assistant/01-council.png)

3. 点议题名进入议题页，查看提案全文、涉及的人（不参加投票）、回避名单、修正案与复议。

![议题页：已列入议程、待表决](img/assistant/02-motion.png)

4. 待附议的议题须等有表决权的成员附议，主持人不代为附议。

![议题页：待附议](img/assistant/03-motion-proposed.png)

表决规则：

- 一般事项过半数同意，记名；涉及人员的事项不记名；建议退组、修订议事规则须三分之二同意。
- 提案须在表决前三天提交；有待表决的修正案的，先表决修正案。
- 研究单元立项由有表决权成员在线表决，赞成超过可投票人数一半即成立，不上会、不经否决期。

## 二、开会与会上表决

### 2.1 开会签到

1. 在左侧导航点「快照与质疑」，下拉到「出勤登记」一节，点「开联席会议签到」，进入会议现场页。已有一场在开的，按钮显示为「进入联席会议现场」；成员的「我的事项」页也显示「正在开：联席会议」链接。

![快照与质疑页：出勤登记一节](img/assistant/16-attendance.png)

2. 会议现场页右上显示四位签到码（三小时内有效）和已签到、请假人数。把这一页共享到屏幕上，与会者在「我的事项」点「签到」输入签到码。
3. 议程一栏列出已列入议程、待表决的议题，并显示出席的有表决权成员人数是否过半。不足半数的不能表决。

![会议现场：签到码、议程、正在讨论的议题](img/assistant/04-live.png)

4. 线上参会的，在页面下方「纪要」一栏点「填飞书会议」，粘贴飞书会议链接或 9 位会议号（加在中心日历上的飞书会议会自动找到）。中台每 5 分钟读一次参会名单，线上参会的自动签到。使用 Zoom 的点「填 Zoom 会议」，散会后中台读参会报告，名字对不上的在此认领。

![填飞书会议对话框](img/assistant/08-feishu.png)

### 2.2 计时发言

1. 在议程中点选一份议题，右侧显示议题全文、讨论和表决。
2. 有表决权的成员、代表和提案人在自己的会议现场页点「申请发言：支持」「反对」或「中立」，进入发言队列。
3. 队列按规则排序：没发过言的在前，支持和反对轮流，同等情况按申请先后；提案人先陈述；每人同一议题最多发言两次。页面显示「请某某（支持）发言」。
4. 当前发言人讲完后，主持人点「发言完毕，下一位」。

### 2.3 会上表决

1. 讨论结束后，点「开始表决」。按钮仅在出席的有表决权成员过半数时可用。
2. 出席的有表决权成员在自己的手机或电脑上投同意、反对或弃权，结束前可改票。涉及本人或已申报回避的不参加投票。页面显示已投票人数。
3. 全部投完后，点「结束表决，公布结果」。页面当场显示同意、反对、弃权票数。
4. 通过的议题进入三个工作日的否决期，正则同时通知中心负责人。

![会议现场下部：签到名单和纪要一栏](img/assistant/05-live-roll.png)

### 2.4 过问

研究单元停滞的过问不表决。负责人到会说明情况和恢复计划后，主持人在会议现场页「过问」一栏写下结果，点「记下过问结果」；也可在议题页点「记下过问结果」。

### 2.5 散会与纪要

1. 全部议题处理完毕，点「散会」，在对话框中点「散会」。签到码随即作废，事先请假的记为请假。
2. 会后点「挂纪要链接」，填写飞书妙记或录屏的链接，请假的人据此在一周内补看并本人登记。

![散会对话框](img/assistant/06-end.png)

![挂纪要链接对话框](img/assistant/07-minutes.png)

### 2.6 补登出勤

未在正则上开会签到的联席会议，在「快照与质疑」页「出勤登记」一节点「补登联席会议出勤」，填写日期，勾选出席和事先请假的人，点「登记」。

![补登联席会议出勤对话框](img/assistant/17-council-backfill.png)

注意：

- 同一类会有一场未散会的，不能再开一场。
- 录音补漏（散会约 1–2 小时后取飞书妙记或 Zoom 逐字稿、找出会上提的质疑）只用于主题研讨会，由研讨会组织者核对记入，联席会议不做。联席会议的纪要以挂上的链接为准。

## 三、会外表决

只有紧急议题可以不等开会，由主持人召集会外表决；修正案、复议、程序动议不在会外表决。

1. 进入标为紧急、已附议的议题页，点「召集会外表决」。
2. 填写开放时长（24 至 168 小时，默认 48），点「开始表决」。正则通知每一名有表决权的成员。
3. 有表决权的成员在议题页投票。到截止时间由中台自动计票，主持人不必手动结束。
4. 投票人数不过有表决权成员半数的，表决无效。两名有表决权的成员要求当面讨论的，议题转到下次会议。

注意：演示环境中暂无紧急议题，故未附会外表决对话框截图。

## 四、否决期、生效与备案

1. 通过的议题列在「已通过，否决期内」，注明否决期截止时间。中心负责人可在三个工作日内否决，否决须写明理由，向全体成员公开。
2. 期满未否决的，由中台定时转为已生效，并把结果落回原申请（研究单元终止或结项即停用、课题档次定档、考核推荐转中心负责人决定、人员推荐转中心负责人决定等）。主持人不必手动办理。
3. 联席会议页下方「试做期结论备案」一节，列出项目双选试做期的期满结论（指导人给出，报联席会议备案）。学期考核中 Intern、Assistant 结论为正常或需改进的，也报联席会议备案，记在「加入与考核」页对应成员下。

## 五、学期成员考核

联席会议每学期组织一次成员考核，由主持人发起，依据双周表、成长主线、研究单元名单、支出和出勤记录，以及合作者匿名短评，不另写总结。Researcher、Rising Star 由进展小组两人审阅，出具意见后提交联席会议表决；Intern、Assistant 由合作的 Researcher 及以上成员评价，报联席会议备案。

### 5.1 发起本学期考核

1. 在左侧导航点「加入与考核」，切换到「学期考核」页签。
2. 点「发起本学期考核」，在对话框中点「发起」。本学期在册的 Intern、Assistant、Researcher、Rising Star 每人一条；已发起的不重复。PI、Director 不在考核范围。

![发起本学期成员考核对话框](img/assistant/12-term-open.png)

3. 发起后，每人一条记录，汇总本学期的研究单元、双周表、快照署名、质疑、主线、出勤和支出。正则通知本人考核已开始。

![学期考核页签：本学期全部成员](img/assistant/11-term.png)

### 5.2 登记进展小组和合作者

1. Researcher、Rising Star：按联席会议的指定，在此人一条下点「登记进展小组」，选两名考核人（Researcher 及以上），勾选「考核人与本人没有私人关系」，点「登记」。
2. Intern、Assistant：默认取本人所在研究单元的负责人评价；需另指定的，点「指定合作者」。
3. 已登记的可点「更换考核人」。登记后正则通知考核人出具意见。

![登记进展小组对话框](img/assistant/13-reviewer.png)

4. 进展小组两人都签署后，意见由正则列入联席会议议程表决；建议退组的须三分之二同意、不记名，本人可以书面申辩一次，决议生效后由中心负责人决定。

注意：

- 本人、与本人有私人关系的人不担任考核人。
- 合作者匿名短评只给考核人和主持人看。合作者在「学期全部」里只看到还在考核、可以写短评的同事，看不到考核意见、改进目标和书面申辩。

## 六、研究单元申请的核对成立

研究单元申请随时可以提交，挂在一个已立项的课题下面。按现行规则，所挂课题负责人同意后，有表决权成员在线表决，赞成过半的即刻成立，不经否决期，也不等主持人核对。

主持人的核对只用于已在会上表决、提交时填写了会议和纪要日期的申请，且只在登记日（每两周一期的第一天）办理。

1. 在左侧导航点「课题管理」，下拉到「研究单元申请」一节。
2. 找到状态为「待核对」的申请，对照联席会议纪要核对会议日期和内容，点「确认成立」。成立后申请人即为负责人。
3. 会议没有这一项、内容与纪要不符或已被否决的，点「退回」，写明原因。

![课题管理页：研究单元申请一节](img/assistant/14-unit-apply.png)

注意：

- 登记日以外的日子，同意、退回和核对一律不能办理，中台提示下一个办理日。
- 「确认成立」按钮在联席会议决议生效、所挂课题负责人同意、否决期届满后才可用。

## 七、主题研讨会

主题研讨会分认知基础、医疗、金融、人文社会四个，组织者由中心负责人指定（至少两位，Researcher 及以上），组织者负责接收投稿、开会、记入质疑和录音补漏。中心助理不设置组织者和排期；需调整组织者的，报中心负责人在「快照与质疑」页办理。

1. 在左侧导航点「快照与质疑」，「主题研讨会」一节显示各研讨会本期的投稿数和组织者。

![快照与质疑页](img/assistant/15-iterate.png)

## 八、任务管理

1. 在左侧导航点「任务管理」。页面列出指派给本人的任务、本人指派的任务和已办结的任务。

![任务管理页](img/assistant/20-tasks.png)

2. 点「新建任务」，填写任务名称、期限、说明和步骤（每行一步），点「创建」。有派任务权限的可选办理人；没有的，任务为本人创建，仅本人和中心负责人可见。

![新建任务对话框](img/assistant/21-new-task.png)

3. 办理人逐步勾选步骤，可为每一步加备注；全部勾选后点「办结」。
