# 七、正则使用手册

- 适用范围：全体成员
- 负责岗位：中心助理
- 中台入口：https://clain-finance.pages.dev （左侧导航「使用指南」）
- 最后整理日期：2026-11-26
- 截图来自演示环境，人名、课题和金额均为虚构。

正则按角色分册说明，每本带截图分步说明。先读《成员通用手册》，再读本人岗位的那一本；同时担任多个岗位的，各读对应的一本。正则里的「使用指南」页列出常用事项的简要步骤，并链接到这里。

## 维护

- 手册与正则不一致的，以正则为准，并在正则右下角点「遇到问题？」说明。
- 正文源文件在 finance-portal 仓库 docs/manual 下，每本一个 Markdown 文件；截图用仓库 scripts/demo 的演示环境（虚构数据）截取，不进仓库。
- 改动成员可见的流程时，在同一个 PR 里更新正则「使用指南」的对应条目和本目录下对应手册，合并上线后重新发布到知识库。
