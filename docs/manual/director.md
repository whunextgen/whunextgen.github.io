# 中心负责人手册

- 适用范围：基础角色为中心负责人的账号
- 负责岗位：中心负责人
- 中台入口：https://clain-finance.pages.dev
- 最后整理日期：2026-11-26
- 截图来自演示环境，人名、课题和金额均为虚构。演示账号为周明远（中心负责人）。

本手册只写中心负责人独有的办理事项。签到、快照、双周表、支出申请等成员通用功能见《成员通用手册》；人员档案的日常办理见《人事岗手册》；联席会议的主持见《中心助理手册》；经费卡、采购、报销入账等财务办理见《财务岗手册》。

中心负责人可以看到全部页面。本手册涉及的页面：中心总览、联席会议、加入与考核、成长主线、快照与质疑（研讨会组织者）、年度预算（总预算与档次、预算编制、预算控制、年度决算）、支出申请、权限管理、人员档案、历史数据。

## 一、中心总览

中心总览是中心负责人的首页汇总，按经费来源、经费去向、各部分、年度进度、风险与提醒排列。

1. 在左侧导航点「中心总览」。
2. 页首为全中心有效期内可用经费，以及各项目占用额度与额度剩余、已下达到各课题和尚未下达的经费。
3. 「各部分」一节分项目、课题、资源三块，点击进入该部分的汇总页。
4. 「年度进度」一节列出各预算年度当前所处环节。
5. 「风险与提醒」一节列出超支、考核节点未达标或预计不达标等事项，点「查看」进入对应经费卡。

![中心总览：经费来源与去向、各部分、年度进度、风险与提醒](img/director/01-center.png)

## 二、联席会议中的中心负责人事项

中心负责人不参加联席会议表决，保留否决权；表决事项涉及人员接收和建议退组的，决议生效后由中心负责人决定。联席会议的议程、开会、表决由中心助理主持，见《中心助理手册》。

### 2.1 否决决议

联席会议表决通过的议题，进入三个工作日的否决期，期满未否决的生效。表决通过时，中心负责人收到通知。

1. 在「联席会议」页「已通过，否决期内」一组中点议题，进入议题页。状态一栏注明否决期截止时间。
2. 决定否决的，点「否决」，写明理由，点「否决」。理由向全体成员公开。
3. 否决后，议题记为被否决；由申请自动列入的议题（研究单元、课题档次、考核、人员推荐等），结果同时落回原申请。

![被否决的议题页：显示表决结果和否决理由](img/director/05-motion-veto.png)

注意：

- 只能否决已通过、仍在否决期内的议题；修正案、复议、程序动议不经否决期。
- 研究单元立项按在线表决办理，赞成超过有表决权成员总数一半的即刻成立，不经否决期。
- 演示环境中暂无处于否决期内的议题，上图为已被否决的议题。

### 2.2 中心负责人特批

特批只有中心负责人能办，不经联席会议，不受登记日限制。每一次都要写明理由，记录全中心可见，并由正则在全员群通报、通知负责人。特批记录列在「联席会议」页「中心负责人特批」一节。

![联席会议页：中心负责人特批一节](img/director/02-specials.png)

特批课题档次：

1. 在「中心负责人特批」一节点「特批课题档次」。
2. 选课题、档次（含年度、金额和名额），填写理由，点「特批」。
3. 特批的档次占该档次的名额；年度预算已下达的，同时下达课题当年额度。年度已核定、尚未下达的，课题负责人可在下达前补填明细，提交时按档次的金额和限制校验，通过即核定。

![特批课题档次对话框](img/director/03-special-tier.png)

特批双周表登记：

1. 点「特批双周表登记」。
2. 选研究单元，填写理由，点「特批」。
3. 该研究单元可在本期登记日之外登记本期双周表，并从本期起计登记；特批了本期、当天登记的，不算漏登。

![特批双周表登记对话框](img/director/04-special-biweekly.png)

## 三、加入名额与加入申请的决定

### 3.1 确定年度名额

博士研究生、博士后、研究助理须在中心负责人确定的年度名额内推荐；没有确定名额的类别不能推荐。

1. 在左侧导航点「加入与考核」，停留在「人员加入」页签。
2. 在「年度名额」表中找到年度和类别，点「确定名额」。
3. 填写名额（人），点「确定」。表中「已用」含在办和已加入的。

![确定年度名额对话框](img/director/06-quota.png)

### 3.2 决定接收

博士研究生、博士后、研究助理的推荐经联席会议表决通过、否决期满后，中心负责人收到通知：接收待决定。

1. 在「人员加入」页签「在办」中找到状态为「待中心负责人决定」的申请。
2. 接收的，点「接收」，可填写说明。中台建档为 Intern（RI），通知推荐人，并通知人事岗在本人首次登录时并入档案。
3. 不接收的，点「不予采纳」，可填写说明，通知推荐人。

演示环境中暂无待决定的加入申请。

### 3.3 决定退组建议

学期考核结论为建议退组的，以及有表决权成员提出的建议退组，经联席会议三分之二同意、不记名表决，决议生效后由中心负责人决定。

1. 学期考核的退组建议：在「加入与考核」页切换到「学期考核」，在「待我办理」中找到该成员，点「同意退组」或「不予采纳」，可填写说明。
2. 成员提议的建议退组：在对应议题页点「同意退组」或「不予采纳」。
3. 同意的，人员档案记为已离开，账号随即停用，并通知本人；不予采纳的，说明记在考核或议题上。

![学期考核页签：已办结的退组建议显示中心负责人的决定](img/director/07-term.png)

## 四、身份认定与德行确认

### 4.1 认定身份

身份分 Intern（RI）、Assistant（RA）、Researcher、Rising Star、PI、Director 六种，靠完成本级全部主线任务并通过考核取得，由中心负责人认定。升降都记一条，写明依据，并通知本人。

1. 在左侧导航点「成长主线」。

![成长主线页（中心负责人本人）](img/director/09-path.png)

2. 下拉到「全中心」一节，可按身份筛选；「本级任务」一列显示已完成数和任务总数。点「任务清单」可查看某人的主线任务。

![成长主线：全中心一节](img/director/10-path-all.png)

3. 在此人一行点「认定身份」，选身份，填写依据，点「认定」。

![认定身份对话框](img/director/11-rank.png)

4. 考核申请（Researcher、Rising Star 等）经联席会议表决同意推荐的，中心负责人收到通知：考核待决定。在「考核」一节此人一行点「决定」，选认可通过或不认可，可选带出此人的人，填写说明。

### 4.2 德行确认

组织和主持中心活动记亨，承担中心的公共事务记利，由中心负责人确认。

1. 在「成长主线」页「德行确认」一节点「确认一项」。
2. 选成员、记入亨或利，填写事项和日期，点「确认」。

![确认一项德行对话框](img/director/11b-merit.png)

注意：

- 「须过问的情形」一节只列出，不自动下调身份，由人事岗通知本人。

### 4.3 指定研讨会组织者

每个主题研讨会至少两位组织者，由 Researcher、Rising Star、PI 担任，Director 不参与组织。组织者由中心负责人指定。

1. 在左侧导航点「快照与质疑」，在「主题研讨会」一节对应研讨会下点「指定组织者」。
2. 一次勾选全部组织者（至少两位），点「保存」。

![指定组织者对话框](img/director/08-organizers.png)

注意：

- 对话框列出全部成员，勾选了 Researcher 以下身份或 Director 的，保存时提示不能担任。

## 五、年度预算

年度预算的流程为：测算总预算、直接确定金额的课题、编档次、批准方案、立项与延续申请、评定、下达执行、年度决算。测算、编档次、下达由财务岗办理（见《财务岗手册》第十二节）；中心负责人办理批准方案、评定完成、预算控制、调剂与超预算审批和年度决算。

### 5.1 批准预算方案

1. 在「财务 › 年度预算」下点「总预算与档次」，选年度。
2. 核对总预算、直接确定金额的课题、各档次金额与名额、未分配。

![总预算与档次：方案编制中](img/director/12-plan.png)

3. 点「批准方案」，核对对话框中的合计，点「批准」。批准后向各课题公布档次，课题即可申请立项或延续。
4. 需财务岗继续修改的，点「撤回批准」；已有课题申请档次的不得撤回。

![批准年度预算方案对话框](img/director/13-approve-plan.png)

### 5.2 评定完成，转入下达

课题档次由联席会议表决评定，表决结果由正则落回各课题的申请。

1. 全部课题的评定结果录入后，在「总预算与档次」页评定一节点「评定完成，转入下达」，点「确认」。
2. 确认后，定档课题的档次金额成为年度上限，已提交的明细成为核定的预算行；立项通过的课题正式成立，未通过的不成立；延续未通过的课题保留，本年度没有预算。财务岗随后在「预算编制」中下达到经费卡，或按课题审核下达。
3. 需要更正的，点「撤回评定完成」；已有预算行下达到经费卡的不得撤回。

![预算编制：评定完成、待下达到经费卡](img/director/14-budget.png)

### 5.3 预算控制：设定课题上限

各课题的年度预算由中心负责人按档设定上限，课题连同下属研究单元的预算合计不得超过上限。各课题上限合计低于年度总预算的部分为机动，用于年中提高上限和超预算支出。

1. 在「财务 › 年度预算」下点「预算控制」，选年度。

![预算控制：年度总预算、上限合计、机动和各课题上限](img/director/15-caps.png)

2. 在课题一行点「设定上限」或「修改上限」，填写上限，点「保存」。上限按档设定：1 千、5 千、2 万、5 万、20 万、50 万，50 万以上按实际数填写。
3. 课题负责人申请提高上限的，列在「待审批的提高上限申请」中。点「同意」，可批准低于申请的数额；点「不同意」须写原因。

![设定上限对话框](img/director/16-cap.png)

注意：

- 研究单元不单独设上限，计入所属课题；中心公共开支不设上限。
- 各课题上限合计不得超过年度总预算。

### 5.4 超预算支出与预算调剂的审批

1. 支出申请超出预算行的，确认环节在研究单元负责人确认和财务岗核对之间增加中心负责人审批。在「支出申请」页点「待我处理」查看。
2. 点「批准」，对话框注明超出预算行的金额；批准后该预算行核定数相应调增，各研究单元核定数合计不得超过年度总预算，申请转财务岗核对。不批准的点「驳回」，写明原因。

![支出申请：待我处理](img/director/17b-mine.png)

3. 研究单元全年累计调剂超过其年度预算 10% 的，由中心负责人审批，列在「年度决算」页「待审批的预算调剂」中。点「同意」，两条预算行的核定数即时调整；点「不同意」须写原因。
4. 联席会议决议追加或调减某一行核定数的，决议生效后，在议题页点「按决议调整核定数」执行。

![支出申请全部列表](img/director/17-requests.png)

### 5.5 年度决算

1. 在「财务 › 年度预算」下点「年度决算」，选年度。页面按研究单元列出核定数、已入账、在途和未用。
2. 年度结束、全部支出申请审批完毕后，点「办理年度决算」，核对后点「确认决算」。决算后该年度预算不可再支出，未用完部分不结转；年末尚未入账的在途支出照常在经费卡上办结。

![年度决算页](img/director/18-review.png)

注意：

- 决算不可撤回。
- 年末盘点与账面不一致的，决算前须有说明（见资产盘点）。

## 六、权限管理

1. 在左侧导航「系统」下点「权限管理」。
2. 「用户」页签仅中心负责人可见。基础角色只有成员、财务岗、中心负责人三种；需授予财务岗或中心负责人的，点「新增用户」按企业邮箱登记，或在其登录后点「修改」。同一人有两个账号的，点「合并」。
3. 「角色」「授权」页签：基础角色之外的角色（如人事岗、中心助理、资源管理员）在「授权」页签点「新增授权」授予，可限定到课题、研究单元或经费卡，可设截止日；点「收回」即时失效。每次授权和收回均通知本人，并记入「授权记录」。

![权限管理：用户页签](img/director/20-users.png)

![权限管理：经费卡页签](img/director/19-admin.png)

注意：

- 批准和经办、批准和入账、确认变更和备案不得由同一人承担，授权时中台自动校验。
- 授权的开始日晚于今天的，到开始日才生效。
