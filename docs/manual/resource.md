# 资源岗手册

- 适用范围：CLAIN 中心接口额度、设备和耗材等资源的登记、申领处理、分发、回收与年末盘点
- 负责岗位：资源管理员
- 中台入口：https://clain-finance.pages.dev
- 最后整理日期：2026-11-26
- 截图来自演示环境，人名、课题和金额均为虚构。

本手册中的演示账号为韩立（资源管理员）。资源管理员在导航「财务 › 资源」下使用资源调配、资产盘点两页，并可查看资源汇总和在途事项。

## 一、资源汇总

需要了解资源全貌和申领进度时使用。

1. 点击导航「资源」组标题旁的「汇总」进入资源汇总页。页首显示在用资源数量，按接口额度和资产分类，并列出申领在办和已停用的数量。
2. 「流程」按「申领 › 批示 › 批准 › 分发 › 使用与盘点」列出各环节的数量：待研究单元负责人批示、待批准、待分发、已办结和在用。
3. 「待办」列出这一部分须办理的事项。
4. 「资源」表列出全部资源的类别、总量、分配情况和状态，点击资源名称进入该资源的详情页。

![资源汇总](img/resource/01-s-res.png)

## 二、资源申领的处理流程

接口额度、设备和耗材都编入年度预算：研究单元负责人申报预算时在预算行上注明所需资源及全年数量，预算下达后成员按计划提交申领。一笔申领依次经过：

1. 申领：成员在「资源申领」页选择一条已编制资源计划的预算行提交，累计申领不得超过计划数量。
2. 批示：由研究单元负责人同意或驳回。研究单元负责人本人的申领、以及中心公共开支下的公共设备申领，直接提交到批准环节。
3. 批准：由资源管理员、财务岗或中心负责人批准，可核减数量。
4. 分发：资源管理员发放额度或交付设备，记入申请人名下。
5. 使用与盘点：资源管理员回写用量、登记编号和存放地点，到期或离岗时收回，年末盘点。

成员看到的「资源申领」页如下，可用于向成员说明申领方法。页面列出研究单元预算的资源计划、公共设备计划、本人名下资源和本人申请；分发后的接口密钥由持有人在此自行取用。

![资源申领（成员视角）](img/resource/12-resource.png)

注意：

- 公共设备仅面向博士后、博士、硕士和研究助理，且须已在某个已立项的课题或研究单元的名单内。
- 资源管理员不得批准本人提交的申领。
- 尚未经研究单元负责人批示的申领，只有中心负责人可以直接批准；资源管理员可驳回。

## 三、资源调配：批准、分发与需求池

### 查看需求池

1. 进入「财务 › 资源 › 资源调配」。页首列出待研究单元负责人批示、待批准、待分发和建议采购金额。
2. 「需求池」按资源汇总全年计划、已分发、在途需求、现有剩余。建议采购量按在途需求的 120% 备货、扣除现有剩余得出，折合金额按单价计算。
3. 需采购的，由对应预算行通过支出申请办理采购经费；批准并到货后在「资产盘点」中入库（见第四节）。

![资源调配](img/resource/02-pool.png)

### 批准

1. 在「资源申请」的「在途」标签中，找到状态为「待批准」的申请（已经研究单元负责人批示）。
2. 核对研究单元、预算行及其计划数量、用途和用量估算，点击「批准」。
3. 填写批准数量，可少于申请数量，核减的在意见中注明原因，确认。
4. 不予批准的，点击「驳回」并填写原因。

### 分发

1. 已批准的申请状态为「已批准，待分发」，点击「分发」。
2. 申请未指定具体资源的，选择分发的资源。
3. 接口额度填写到期日（默认为申请月份的月底）；资产填写归还日，长期使用的留空。选填备注后确认。
4. 分发后生成一条分配记录，记入申请人名下。接口额度的个人密钥随后在「资产盘点」的额度台账中发放（见第四节）。

![分发](img/resource/03-pool-fulfil.png)

5. 点击「全部」标签可查看历史申请及批示、批准意见。加急的申请和出资研究单元成员的申请排在前面，分别标「加急」「优先」。

![资源申请（全部）](img/resource/04-pool-all.png)

## 四、资产盘点：登记、充值入库、分配与回收

「资产盘点」页分「接口额度」和「资产与库存」两个标签，分别管理接口账号和设备、耗材。

1. 进入「财务 › 资源 › 资产盘点」。页首列出接口账号数（含已保存密钥的个数）、资产数（单件与成批）、在用分配和需补货数量（接口用量达八成，或库存已发完）。

![资产盘点（接口额度）](img/resource/05-stock.png)

### 登记资源

1. 在相应标签下点击右上角「登记接口额度」或「登记资产」。
2. 接口额度填写名称、服务商、模型或套餐、账号、总配额、单位、币种和服务商账户余额。不要在此填写密钥。
3. 资产填写名称、类别、规格型号、资产编号、库存数量、单位、单价、随附配件和存放地点。单件资产（一台设备）不填库存，同一时间仅可登记在一人名下；成批资产（同一型号多件、耗材）填写库存数量，按件申领。
4. 已登记的资源点击「修改」调整；取消勾选「在用」即停用，停用后不可再申请和分配。

### 充值与入库

采购须先经预算：该笔款项须先在支出申请中由预算行提出并获批准，才能充值或入库。

1. 接口额度点击「充值」：选择对应的已批准支出申请，填写充值额度、实付金额、充值日和供应商。充值后总配额和服务商账户余额同时增加。

![充值](img/resource/07-stock-recharge.png)

2. 切换到「资产与库存」标签，表中列出库存、已发出、剩余、单价和存放地点。

![资产与库存](img/resource/08-stock-asset.png)

3. 成批资产点击「入库」：选择对应的已批准支出申请，填写数量、单价、验收日和供应商。验收后库存增加。

![验收入库](img/resource/09-stock-instock.png)

4. 「充值记录」「入库记录」列出每次充值或入库的数量、金额、出资研究单元、对应支出申请和经办人。

### 期初余额与外币计价

旧门户的充值、往年充值剩下的接口额度，不对应本年的支出申请，按「期初余额」录一次。

1. 进入该接口资源的详情页（资源汇总或资产盘点中点资源名称），在「入库记录」上方点「录入期初余额」。
2. 填平台后台显示的账户余额、计价单位、截至日期和来源。平台按美元等外币计价的，计价单位填该外币，并填折算汇率（1 单位合多少元，按市场汇率）。
3. 录入后，这项额度的申请、批准、发放和密钥额度都按该计价单位；和课题预算比较时，按汇率折成人民币。汇率可在详情页点「更新汇率」按市场更新。

注意：

- 每项资源只录一次期初余额，之后的充值按支出入库。
- 已有在办申请或在用额度的，不能改计价单位。

### 直接分配

不经申请直接记入指定人员名下，用于补记和续期。

1. 在资源右侧点击「分配」。
2. 选择使用人，填写额度或数量、起始日、到期日（长期使用的留空）和用途，确认。

![直接分配](img/resource/06-stock-give.png)

### 额度台账与领用台账

1. 「额度台账」（接口）或「领用台账」（资产）列出各人名下资源；「在用」只列当前有效的，「全部」含已收回和已到期的。
2. 接口额度按服务商账单点击「回写用量」，填写截至某日的累计已用。剩余不足一成的标红。

![回写用量](img/resource/11-alloc-usage.png)

3. 接口额度点击「发放密钥」，填写发放给该持有人的密钥。持有人可在「资源申领」中自行取用，每次取用均有记录。
4. 资产点击「编号存放」，登记资产编号和存放地点。
5. 到期或离岗时点击「收回」，填写收回日。接口额度收回时，发放给该持有人的密钥同时从中台删除；成批资产的库存相应恢复。

### 密钥管理

1. 接口账号的共用密钥在「接口账号」表中点击「保存密钥」或「更换密钥」填写，页面仅显示掩码；留空保存即删除现有密钥。
2. 账号共用密钥仅财务岗可取用；发放给个人的密钥仅持有人和财务岗可取用。每次取用记入「密钥取用记录」。

注意：

- 中台收回密钥后，服务商侧的密钥须另行停用或轮换。
- 密钥不得写入申请、备注或资源登记的任何字段。

## 五、年末盘点

年度决算前须核对账面与实际。接口核对服务商账户的实际余额；设备和库存核对实际清点数量。购置的设备属中心公共设备，不分研究单元，统一在此盘点。

1. 在「资产盘点」页下部的「年末盘点」中选择年度，接口和资产分别在两个标签下盘点。
2. 点击某项资源的「盘点」，填写实盘数，实盘与账面不一致的在说明中注明原因，保存。已盘点的可「重新盘点」。
3. 盘点结果与账面不一致的，会列入「年度决算」页的「年末盘点差异」，决算前须有说明。

![年末盘点](img/resource/10-stock-check.png)

注意：

- 年度决算后盘点结果不可修改。

## 六、单项资源详情

需要查看某一项资源的完整经过时使用。

1. 在资源汇总、需求池或资产盘点中点击资源名称，进入资源详情页。
2. 页首显示总量、已分配、当前持有人数和单价，流程按「入库 › 申领 › 分配 › 使用与盘点 › 回收」列出各环节记录数。
3. 下方依次列出当前分配、申领记录、入库记录和已回收的分配。

![资源详情](img/resource/13-res-detail.png)

## 七、在途事项

1. 点击导航「在途事项」，查看尚未办结的资源申请及其当前等待对象：研究单元负责人批示、财务岗批准或财务岗分发。
2. 本页只供查看。办理资源申请请进入「资源调配」。

## 八、研究单元以名义币换 GPU 卡时和 API 额度

API 额度和 GPU 卡时一律用研究单元账上的名义币兑换，由研究单元负责人在研究单元页面办理，课题不直接兑换资源。

1. 个人的名义币或实际币只能投给研究单元，投入后都成为研究单元的名义币；课题也可以把「算力与模型接口」的预算兑成名义币记入研究单元的账上。研究单元账上的名义币季末作废。研究单元的负责人在研究单元页面用研究单元账上的名义币点击「换 GPU 卡时」，按标价从研究单元账上扣除。
2. 卡时标价由财务岗每季度在「代币 › 代币系统」随兑换比例公布，卡时的有效期由中心负责人在同页「代币参数」中设定；标价未定时暂不能兑换。
3. 换得的卡时买后在有效期内有效，集群按换得的卡时设定额度，不经资源调配和资产盘点办理。
4. API 额度：研究单元负责人点「换 API 额度」，按本季度公布的比例（1 币兑多少元 API 额度）换得额度，计入这个研究单元的 key。额度按 key 所在接口资源的计价单位记：额度 = 名义币 × 比例 ÷ 资源的折算汇率（1 美元合多少元），例如本季度 1 币兑 1 元、资源按美元计价、汇率 6.66 时，1 币约合 0.15 美元；人民币计价的不折算。每笔记下当时用的汇率。key 发到研究单元，不发到个人，名单内成员共用，与 GPU 每个研究单元一个 QOS 一致；这类额度不经「资源调配」，也不进额度台账。
5. 指定资源和季度上限：进入「资产盘点」的「接口额度」标签，在「研究单元 API key」一栏点「指定资源」（指定后为「登记库存」），选研究单元的 key 开在哪个接口资源上，并填库存。指定之前研究单元不能换。每季度全中心换出的 API 额度，不超过当季公布的总额（按资源的现行汇率折算），换满即止；现有库存只做登记对账，不计入上限；这一栏按资源的计价单位显示本季度可换、已换和剩余。库存按资源的计价单位填服务商账户里的余额。本季度已有研究单元换过的，不能改到另一个资源。汇率在接口资源的详情页「更新汇率」。
6. 发放 key：研究单元换了 API 额度后，财务岗收到通知。在服务商处为这个研究单元开 key 并把额度加上，在「研究单元 API key」一栏点「发放 key」加密保存，页面仅显示掩码；保存后通知负责人和名单内成员。之后再换的额度加到同一个 key 上。
7. 名单内成员在研究单元页自行取用，每次取用均记入「密钥取用记录」，「密钥归属」一栏写明研究单元。
8. 换 key：成员移出名单时，财务岗收到提醒，该研究单元标「待换 key」。在服务商处作废旧 key，再点「更换 key」保存新 key，标注随即消除，名单内成员收到通知。
9. 代币不是经费，不与经费卡和学校账目发生关系。
