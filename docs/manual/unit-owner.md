# 研究单元负责人手册

- 适用范围：研究单元负责人（含拟申请成立研究单元的成员）
- 负责岗位：中心助理
- 中台入口：https://clain-finance.pages.dev
- 最后整理日期：2026-11-29
- 截图来自演示环境，人名、课题和金额均为虚构。演示账号为唐书言（Researcher，负责研究单元「触觉反馈下的抓取策略」）；支出确认一节用许若溪（Assistant，负责研究单元「大模型评测基准的可信度」）。

研究单元挂在一个已立项的课题之下，使用所挂课题的预算，不单独编预算，也不参加年度评定。负责人管理成员名单，按期登记双周表，提交快照并组织回应质疑，确认成员的支出申请，管理研究单元的池子和名义币。签到、请假、日常任务、本人支出申请等成员通用事项见《成员通用手册》，本手册不重复。

研究单元的期次为两周一期，与名义币的期次相同。每期第一天为登记日：研究单元申请的同意、退回、核对和双周表登记都只在登记日办理。

## 一、查看本人负责的研究单元

登录后进入「我的事项」。页首列出所在研究单元和所属课题；「待办」区块列出与本人有关的事项，其中登记日当天会出现「今天是登记日：某研究单元的双周表请在今天 24:00 前登记」，逾期未登记的研究单元也在此提示。

![我的事项：待办中列出双周表登记提醒](img/unit-owner/01-home.png)

研究单元的全部信息在其详情页：左侧导航「课题 › 课题管理」，在列表中点研究单元名称进入。详情页自上而下为预算与流程、本回合快照与四问质疑、待回应质疑、支出与报销、调剂、池子与成果、ARR 担保、投稿与评审、成员、设备、接口额度、资源申领。

![研究单元详情页页首：负责人、年度预算流程和本回合快照](img/unit-owner/05-unit-detail.png)

## 二、申请成立研究单元

成员拟在某个已立项课题之下开展一项研究时，申请成立研究单元。申请全年随时可以提交；所挂课题负责人的同意、退回只在登记日办理。成立后申请人即为负责人。

1. 进入「课题 › 课题管理」，滚动到页面下方「研究单元申请」一栏。栏内列出本人提交的申请及其进度（待课题负责人同意、待联席会议表决、已成立、已退回）。

   ![课题管理页下方的研究单元申请一栏](img/unit-owner/02-unit-apply-list.png)

2. 点「申请成立研究单元」，在对话框中填写：
   - 所挂课题：只能选已立项、在用的课题，中心公共开支之下不设研究单元；
   - 研究单元名称：不超过 60 字，同一课题下不得重名；
   - 联席会议通过的日期、会议纪要发出的日期：只有已在会上表决过的才填，一般留空；
   - 说明：研究内容，拟使用的经费和资源，不超过 1000 字；
   - 拟加入的成员：选填，成立后可再调整。

   ![申请成立研究单元对话框](img/unit-owner/03-unit-apply-dialog.png)

3. 点「提交申请」。正则自动把申请列入联席会议议程，并通知所挂课题的负责人。
4. 所挂课题负责人在登记日同意后，联席会议有表决权的成员在中台在线表决。申请人本人即所挂课题负责人的，视为已同意，提交后即开始表决。
5. 赞成人数超过开始表决时可以投票的有表决权成员总数一半的，研究单元即刻成立，正则在全员群通报，并通知负责人和名单内成员；赞成已不可能过半的，即为未通过。在线表决的议题页显示表决规则和投票情况。

   ![研究单元立项的在线表决议题页](img/unit-owner/04-unit-online-vote.png)

6. 被退回的申请，在「研究单元申请」一栏点「修改」，按退回原因修改后重新提交；不再申请的点「撤回」。所挂课题不能修改，须撤回后重新申请。

注意：

- 申请涉及本人或其合作者的有表决权成员回避，不计入总人数。
- 研究单元在线表决不转到会上讨论，也不经否决期。
- 已填写会议通过日期的申请，由助理在登记日对照纪要核对后确认成立。

## 三、管理成员名单

只有名单内的人员可以从本研究单元的预算行提交支出申请、申领接口额度。负责人可直接新增和移出成员，无需本人确认；负责人默认在名单内。

1. 进入研究单元详情页，滚动到「成员」一栏。表中列出成员、加入日期、加入人、池子份额、占比和名下接口额度；已移出的成员列在表下。

   ![研究单元详情页的成员一栏](img/unit-owner/06-unit-members.png)

2. 新增：点「新增成员」，选择成员，点「加入名单」。

   ![新增成员对话框](img/unit-owner/07-member-add.png)

3. 移出：在该成员一行点「移出」，确认后移出。移出后该成员不能再从本研究单元提交支出申请和申领接口额度，已提交的申请照常办理。

注意：

- 成员名下尚有本研究单元的接口额度的，须先在详情页「接口额度」一栏收回，才能移出。收回后发放给该成员的密钥同时从中台删除。
- 新加入的 Intern、Assistant 需要试做期的，改用「双选」页的「加入并开始试做」，见第七节。

## 四、登记双周表

每个研究单元每两周登记一次双周表，交上一期的结果和这一期的计划。负责人和名单内成员都可以登记。

1. 登记日当天，进入左侧导航「双周表」。「我的研究单元」一栏中，当天可登记的研究单元标为「今天是登记日，尚未登记」，下方显示登记表。
2. 填写：
   - 写作进度：想法、摘要、首图、核心结果表、完整初稿、投稿稿中选一项；
   - 本轮回答的问题：每轮只回答一个问题，不超过 300 字；
   - 已完成的工作与阶段结果（不超过 2000 字）、本轮改变的判断（不超过 1000 字）；
   - 遇到的问题：选填；
   - 成员分工（不超过 500 字）、下一轮安排与预期（不超过 1000 字）。

   上一期已登记的，表单上方显示上一次的本轮问题和下一轮安排，写作进度和成员分工沿用上一次的内容。

   ![双周表页：登记日当天的登记表](img/unit-owner/08-biweekly.png)

3. 点「登记」。当天 24:00 前可以修改，按钮变为「更新登记」。
4. 「全部研究单元」一栏按课题列出各研究单元本期是否已登记、最近写作进度和连续未登记期数，点研究单元名称查看历次登记。

   ![全部研究单元的登记情况](img/unit-owner/09-biweekly-all.png)

注意：

- 双周表只在登记日当天登记，当天 24:00 截止，不补登。登记日已过的，页面提示下一个登记日。
- 一期未登记的研究单元，由联席会议优先过问；未登记双周表的研究单元不参加方向会汇报。
- 连续两期未登记的转为停滞，正则自动列入联席会议议程「过问」，负责人到会说明情况和恢复计划，不表决，由主持人记下过问结果。停滞满两期仍未恢复的，自动生成终止研究单元的议题表决；其间恢复登记的，两项都自动撤下。
- 因故在登记日之外登记，只能由中心负责人特批。特批写明理由，在全员群通报。
- 研究单元成立之前的期次不计。

## 五、提交快照并投稿主题研讨会

每两周是一次快照：研究单元把当期的写作草稿提交给主题研讨会，会上提出的质疑逐条记入，每条指明针对理、据、体、用中的哪一问。

1. 进入左侧导航「快照与质疑」。「本期快照」一栏列出本人负责或在名单里的研究单元，以及本期快照、研讨会接收情况和未回应的质疑条数。

   ![快照与质疑页：本期快照一栏](img/unit-owner/10-iterate.png)

2. 在研究单元一行点「提交快照」，填写写作草稿的链接、本期改了什么（选填），勾选本期在草稿里有改动的成员（日常任务按此判定），点「提交」。本期内可以点「更新快照」修改。

   ![提交本期快照对话框](img/unit-owner/11-snapshot-dialog.png)

3. 快照提交后，该行出现「提交研讨会」，点开后选择研讨会（认知基础、医疗、金融、人文社会，可多选），点「提交」。
4. 所提交研讨会的组织者决定接收为口头报告或海报，或不接收。未接收的，当期不展示，可在下一期重新提交。组织者点错的，本期内可以撤回，改回投稿待定后重新决定，届时会收到通知。
5. 会上记入的质疑出现在研究单元详情页「待回应质疑」一栏，以及「快照与质疑」页下方「未回应的质疑」表中。

注意：

- 快照是这一期写作草稿的样子：整篇都在，理、据、体、用四问都有回答。快照不打分。
- 同一期可以交给不止一个研讨会。快照所在研讨会的讨论结束后，本期快照不能再更新。

## 六、处理质疑队伍和入队申请

每条未回应的质疑由几个人组队回应：把回应写进草稿，随下一次快照展示。下一期的会上没有人再提的，即为已回应，记 16 名义币，由当期有分配资格的队员平分。

1. 未回应的质疑全中心公开，在「快照与质疑」页下方按理、据、体、用和研究单元筛选。

   ![未回应的质疑表](img/unit-owner/12-open-queries.png)

2. 负责人组队：在本研究单元的质疑一行点「加人」，选择成员，点「加入队伍」。本研究单元和其他研究单元的人都可以入队。需要调整的，在队员姓名旁点「移出」。
3. 其他成员在质疑一行点「申请入队」并提交后，正则通知负责人；入队由负责人加人，申请人不能自行加入。负责人确认后按第 2 步加人。

   ![申请入队对话框（成员一侧所见）](img/unit-owner/13-ask-join.png)

4. 研究单元详情页「待回应质疑」一栏按条列出队伍和待组队情况；「审阅意见」列出其他研究单元的人当日审阅本单元快照提的意见，负责人点「采纳」，记入审阅人的「利」，可在下一次研讨会上作为质疑提出。

   ![研究单元详情页的待回应质疑一栏](img/unit-owner/14-unit-iterate.png)

注意：

- 新入队的队员自下一期起参与分配，入队当期的名义币仍由原有队员平分。
- 入队回应质疑的其他研究单元人员不进本研究单元的成员名单。
- 质疑由研讨会组织者在会上记入，负责人不能自行记入或删除。

## 七、确认成员的支出申请

成员从本研究单元的预算行提交支出申请后，先由研究单元负责人确认，再由财务岗核对；超出预算行的，中间增加中心负责人审批。

1. 进入「课题 › 支出申请」。表头为「我的申请及负责研究单元的申请」，「待确认」计数为等本人确认的笔数。
2. 在待确认的申请一行点「确认」：
   - 未超出预算行的，确认后提交财务岗核对；
   - 超出预算行的，对话框提示超出金额，确认后提交中心负责人审批。
3. 不同意的点「不同意」，写明原因后提交，该笔申请终止，申请人可查看原因。
4. 已确认的申请，状态下方显示「某某 已确认 · 某某 已核对」；负责人本人提交的显示「负责人本人提交」。

![支出申请列表：负责人已确认、财务岗已核对的申请](img/unit-owner/15-requests.png)

注意：

- 本人提交的申请须由负责人或副手中的另一位确认。
- 研究单元详情页「支出与报销」一栏也列出本研究单元在途的申请，可在该处确认。

## 八、双选与试做期

中心已有的 Intern、Assistant 和硕士研究生在「双选」页选择参与的课题和研究单元。负责人在此看到意向，谈妥后把成员加入名单；新加入的 Intern 和 Assistant 可以开一个月的试做期。

1. 进入左侧导航「双选」。「我负责的招募与成员」一栏列出本人负责的研究单元、成员人数、收到的意向和进行中的试做期。课题和研究单元的介绍取自立项时的说明，负责人不另填。

   ![双选页：我负责的招募与成员](img/unit-owner/16-select.png)

2. 加入并开始试做：在研究单元一行（或某条意向后）点「加入并开始试做」，填写：
   - 成员、指导人（Researcher 及以上，不能是本人）；
   - 试做期至：今天之后、一个月以内；
   - 首个小任务：做什么（一句话，不超过 80 字）、交付什么（不超过 1000 字，细节写在这里）、何时提交（须在试做期内）；
   - 勾选「指导人与该成员没有私人关系」。

   点「开始」后，该成员加入名单，同时开始试做期。

   ![加入并开始试做对话框](img/unit-owner/17-trial-start.png)

3. 阶段反馈：试做期内成员提交阶段进展后，指导人点「阶段反馈」，写明已完成什么、遇到什么困难、下一阶段继续或调整什么。
4. 期满结论：指导人点「期满结论」，从继续参与、延长试做（只能一次，不超过一个月）、调整课题或指导安排（由科研助理协调）、结束本课题参与中选一项，对照考察标准写明理由。延长的另填延长日期和延长期间的任务。

注意：

- 试做期适用于 Intern 和 Assistant；已在名单中的成员不重新试做。
- 考察标准按身份：Intern 和硕士研究生看研究热情和投入；Assistant 另看研究能力。均不以发表为标准，负责人和指导人不另设标准。
- 期满结论报联席会议备案，只影响该研究单元的成员资格，不影响身份。结束参与的，本人可以在七日内向联席会议申诉，表决通过的恢复成员资格。

## 九、研究单元池子与代币

研究单元就是一个池子：个人把名义币或实际币投给研究单元，投入多少就记多少份额，换资源花掉或季末作废只减余额，不减份额。回应质疑和其他任务一样只发名义币，不直接记份额。研究单元取得第一个经核对的外部成果时池子解锁；铸造率挂牌后，按份额把实际币铸造给个人，实际币不过期。投入的币都成为研究单元的名义币；课题负责人也可以把「算力与模型接口」的预算兑成名义币记入研究单元的账上。研究单元账上的名义币当季有效，季末（1、4、7、10 月最后一天）作废。API 额度和 GPU 卡时一律由研究单元负责人用单元账上的名义币兑换，课题不直接兑换资源。

1. 进入研究单元详情页，滚动到「池子与成果」。上方四格为四级成果：一级公开发布（arXiv 预印本或公开的投稿页）、二级完整发布、三级外部反响、四级同行认可；下方为池子（各人投入的份额、未回应的质疑、是否锁定）和名义币（账上余额，当季作废；已换卡时、标价、已换 API 额度）。

   ![池子与成果、名义币一栏](img/unit-owner/18-pool.png)

2. 提交成果：点「提交一级成果」，填写可公开访问的链接和说明（选填），点「提交」。一级成果提交后才能提交二至四级；四级须另填录用的会议或期刊。

   ![提交成果对话框](img/unit-owner/19-outcome.png)

3. 助理只核对成果是否属实、是否属于本研究单元，不评价好坏。退回的，按退回原因重新提交。
4. 换 GPU 卡时：研究单元账上有名义币且标价已公布时，负责人点「换 GPU 卡时」，填写卡时数（正整数），点「换」，按标价从研究单元账上扣除。
5. 换 API 额度：研究单元账上有名义币时，负责人点「换 API 额度」，填写换出的名义币，点「换」。按财务岗本季度公布的比例（1 币兑多少元 API 额度）从研究单元账上扣除，换得的额度计入本研究单元的 key。额度按 key 所在平台的计价单位记，平台按美元计价的，按财务岗登记的汇率把元折成美元，对话框里写明 1 币折多少美元。全中心每季度可换的 API 额度不超过当季公布的总额（按汇率折算），换满即止，现有库存只做对账、不计入，对话框里提示本季度还可换多少。这个上限不是给哪个研究单元的额度，负责人换了之后才计入本研究单元的 key。本季度比例尚未公布、财务岗尚未指定 key 所在的接口资源或已换满的，按钮不可用。
6. API key：key 发到研究单元，不发到个人，名单内成员共用。财务岗发放 key 后，负责人和名单内成员收到通知，在「名义币」下方的「API key」一栏点「取用 key」，每次取用均有记录；负责人在这一栏看得到最近的取用记录。本研究单元还没换额度的，这一栏写明「还没有换 API 额度」；换了但财务岗尚未发放的，写明「财务岗尚未发放 key」，这两种情况都取不到 key。
7. 成员移出名单后不能再取用 key，资源管理员、财务岗等有「保存和更换密钥」权限的人收到提醒更换 key，换好之前这一栏标注「待换 key」；换好后旧 key 作废，名单内成员收到通知，重新取用。

注意：

- 代币不是经费。任何人都可以把自己的名义币或实际币投给研究单元（「投入代币」），先扣快过期的名义币，再扣实际币。投入后和课题预算兑入的一样，都成为研究单元的名义币，季末作废。
- 只能单向兑换：名义币换成 API 额度或卡时后不能换回，也不能兑回预算或人民币。由预算兑来的名义币只能换资源，不按份额分给个人。
- key 不得转发名单外的人或写入代码仓库。
- 换得的卡时买后 8 周内有效，集群按此设定额度。
- 池子上限按联席会议立项时核定的数，由助理或财务岗登记，超出上限的不计。

## 十、学期考核中作为合作者评价成员

联席会议每学期组织一次成员考核。Intern、Assistant 由合作的 Researcher 及以上成员评价，默认由所在研究单元的负责人担任，报联席会议备案。

1. 进入左侧导航「加入与考核」，点「学期考核」。「我的考核」为本人的考核；「待我办理」列出需要本人出具意见或写匿名短评的考核。每条考核下方汇总本学期记录：所在研究单元、双周表登记次数、快照署名、入队回应和提出质疑、主线完成、出勤、支出申请。

   ![学期考核页：我的考核与待我办理](img/unit-owner/20-term.png)

2. 被指定为考核人的，点「出具意见」，选择结论（正常、需改进、建议退组），填写意见；需改进的，写明与本人商定的改进目标和期限（约两个月）。点「起草并签署」。
3. 两位考核人的，另一人核对后点「签署」。正常、需改进的报联席会议备案；建议退组的列入联席会议议程，须投票者三分之二同意、不记名，本人可以书面申辩一次。
4. 改进期满，考核人点「记录改进目标」，记下是否达成。
5. 合作过的成员可点「写匿名短评」，三百字以内，写具体的事。短评只给考核人和联席会议主持人看，不显示作者；考核意见出具之前可以修改。

   ![写匿名短评对话框](img/unit-owner/21-term-comment.png)

注意：

- 考核人由联席会议主持人指定；本人、与被考核人有私人关系的不担任。
- 考核依据中台记录，不要求被考核人另写总结。

## 十一、研究单元结项或终止

研究单元工作完成或不再继续时，负责人在联席会议提议结项或终止。

1. 进入左侧导航「联席会议」，点「提议终止或结项」。
2. 选择研究单元，类别选「结项：工作完成」或「终止：不再继续」，填写理由，点「提交」。
3. 负责人本人申请的免附议，直接列入议程；其他成员提议的须附议。
4. 决议生效后研究单元停用，成员可以加入其他研究单元。

![联席会议页：议题列表和提议终止或结项入口](img/unit-owner/22-council.png)

联席会议的提案、附议、发言和表决办法见《课题负责人手册》第九节。


## 课题与研究单元人数口径

双选页和课题管理列表中，课题人数为直属成员与下属有效研究单元成员的并集，按账号去重，同一人加入多个研究单元或同时在直属名单中只计一次。研究单元仍只统计本单元。仅计启用账号且加入日期已生效、尚未退出的成员；已停用、待立项和公共项目不纳入研究汇总。课题旁同时注明直属人数。负责人仅在实际有成员记录时计入，不另加一人。

课题详情的「直属成员」维护的仍是原直属名单。人数汇总不创建父课题成员关系，不改变预算、支出、资源、份额或审批权限。真实名单直接从中台读取，无需重新导入。
