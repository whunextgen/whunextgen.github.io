# 财务岗手册

- 适用范围：CLAIN 中心财务岗在中台「正则」中办理的项目与经费卡、支出、报销入账、人员经费、结清和年度预算等业务
- 负责岗位：财务岗
- 中台入口：https://clain-finance.pages.dev
- 最后整理日期：2026-11-26
- 截图来自演示环境，人名、课题和金额均为虚构。

本手册中的演示账号为何静（财务岗）。凡写明由中心负责人办理的环节，财务岗在页面上看不到对应按钮，属正常情况。

## 一、登录后的首页与导航

登录后进入「我的事项」。财务相关的待办集中列在本页的待办表中，每条右侧的链接直接进入办理页面。

1. 登录中台，首页「待办」一栏列出与本人有关的事项，例如年度预算申报进度、待提交学校的申请、采购中、待回写、资源待分发等。
2. 点击某条待办右侧的「提交」「推进」「回写」「查看进度」等链接，进入对应页面办理。
3. 左侧导航中，「财务」之下分为三组：年度预算（总预算与档次、预算编制、预算控制、年度决算、预算参数）、项目（项目管理、经费卡管理、采购、报销与入账、人员经费、明细账校准、经费结清）、资源（资源调配、资产盘点）。「采购与报销要求」在系统组中。

![我的事项与待办](img/finance/01-home.png)

## 二、中心总览与各汇总页

需要了解全中心经费全貌、各年度预算所处环节或某一部分的待办时使用。各汇总页只供查看，办理时点击页内链接进入具体页面。

1. 在导航中点击「中心总览」。页首显示全中心有效期内可用经费，下方两条图分别是经费来源（各项目占用额度与额度剩余）和经费去向（已下达到各课题与尚未下达）。
2. 「各部分」列出项目、课题、资源三部分的概况，点击进入该部分的汇总页。
3. 「年度进度」列出各预算年度当前所处环节。
4. 「风险与提醒」列出超支、考核节点未达标或预计不达标、执行预警，点击「查看」进入对应经费卡。

![中心总览](img/finance/02-center.png)

5. 点击导航「项目」组标题旁的「汇总」进入项目汇总页。页面按「申请下达 › 学校下达 › 支出申请 › 提交报销 › 学校入账 › 到期结清」列出各环节数量，下方是这一部分的待办，以及按「项目 › 经费卡 › 明细、执行」逐级展开的项目列表。

![项目汇总](img/finance/03-s-fund.png)

6. 「课题汇总」按「申报 › 汇总报批 › 核定下达 › 支出申请 › 提交报销 › 学校入账 › 年度决算」列出当年课题预算的执行情况，可逐级展开到研究单元和预算行；页面下部还有资源申领和投稿评审的概况。

![课题汇总](img/finance/04-s-topic.png)

注意：

- 中心总览中的「预计到期回收」指到期回收的经费卡按当前速度预计在到期时剩余、将被学校收回的金额。

## 三、项目管理

项目指学校、国家等渠道批复下来的经费来源，记额度和期限。额度不是可直接使用的钱，每次下达的经费另在项目下开经费卡。收到新的任务书或合同时，先建项目，再开经费卡。

### 新建或修改项目

1. 进入「财务 › 项目 › 项目管理」，点击右上角「新建项目」。
2. 填写项目名称，按任务书或合同选填来源渠道、经费性质、负责人、额度、期限开始和结束。
3. 选择科目模板。
4. 选择经费卡到期处理（到期回收、到期退回或结转）：到期回收的，结余由学校收回，回到项目的额度剩余，可重新申请；结转的，结余带入下一张同卡号经费卡。
5. 选择项目结束处理：财政项目等结题时须上缴结余的，选「结余上缴」，结题时额度剩余记为上缴数；否则选「无须上缴」。
6. 点击「新建」。已有项目在项目卡片下方点击「修改」。

![新建项目](img/finance/06-new-project.png)

### 处理尚未归入项目的经费卡

此前直接登记的经费卡列在页首「尚未归入项目的经费卡」中，须逐张确定所属项目。

1. 属于已建项目的，点击「归入项目」，选择项目后确认。只有科目模板与该卡相同的项目可选。
2. 项目尚未建立的，点击「据此新建项目」，补全来源渠道、额度和期限。几张卡属于同一项目的，先据其中一张新建项目，再把其余几张归入。

![项目管理](img/finance/05-funds.png)

### 查看项目详情

1. 点击项目名称进入项目详情页。页首显示额度剩余（未填额度的显示有效期内可用）和额度构成图：各经费卡的已入账、已承诺、可用，以及额度剩余。
2. 「流程」一栏按「立项 › 下达 › 执行 › 到期处理 › 结题」显示当前所处环节。
3. 「经费卡」一栏列出各次下达的经费卡，执行条上的竖线为时间进度。卡号可点击进入经费卡详情。

![项目详情](img/finance/07-fund-detail.png)

### 开经费卡

学校每下达一次经费，在对应项目下开一张经费卡。

1. 在项目卡片下方或项目详情页「经费卡」一栏点击「开经费卡」。
2. 填写下达年度、经费卡号（按学校财务系统填写）、名称（留空则与项目同名）。同一年度可开多张，如直接费、间接费各一张。
3. 选填申请数和下达数。下达数也可在以后导入学校明细账时按收入明细自动得出。
4. 填写下达日、单据截止日（经费卡有效期至此，可跨年度）和结清日（结清前须填写）。
5. 点击「开卡」。

![开经费卡](img/finance/08-open-card.png)

注意：

- 同一下达年度内经费卡号不得重复。
- 下达年度不在项目期限之内的经费卡标「期限外」，系统不拦截，只作提示。项目已延期的，修改项目期限。
- 开错的经费卡，在尚未录入预算、没有支出和其他记录时可点击「删除」；没有经费卡的项目可以删除。
- 项目下的经费卡全部结清后，项目卡片出现「结题」按钮。结题后不得再修改项目或开卡。
- 已在用的经费卡可点击「改归属」移到科目模板相同的其他项目。

## 四、经费卡管理与经费卡详情

经费卡记项目某次下达的经费，支出只与有效期内的经费卡核对。日常查看额度和执行进度、录入明细、设置考核节点、导入学校明细账都在经费卡页面办理。

### 查看全部经费卡的额度与执行进度

1. 进入「财务 › 项目 › 经费卡管理」。页首四项为现行预算、决算数（学校已入账）、承诺（已核对未入账）和可用（预算 − 承诺 − 决算）。
2. 「执行进度与时间进度对比」逐张列出经费卡，竖线为时间进度，竖线左侧未填满的部分即落后于时间进度的部分，右侧为预计到期结余。到期回收的经费卡结余不可留用，优先排列。
3. 「执行预警」列出进度落后的经费卡及建议，例如至截止日每月需入账的金额。
4. 下方「经费卡」「考核节点」两栏汇总各卡情况，点击卡名进入详情。

![经费卡管理](img/finance/09-cards.png)

### 经费卡详情

1. 页首显示可用额和执行图（已入账、已承诺、可用），右侧列出下达数、已入账、已承诺、有效期和学校余额。
2. 流程按「下达 › 支出申请 › 执行 › 到期 › 结清」显示当前环节和剩余天数。
3. 「基本情况」中可修改下达数和控制方式。学校只管总额、不按科目控制的经费卡选「只控总额」，支出只与整张卡的可用额核对；学校按科目下达并控制的选「按科目控制」。
4. 「明细与执行」：首次点击「录入明细」，按任务书的预算表逐项填写预算科目和年初预算，任务书中有而列表没有的科目点「新增预算科目」。保存后，把学校明细账里的学校科目逐个「对应到预算科目」。
   - 每个科目名后的「逐笔 N」展开该科目下的每一笔支出（日期、摘要、学校科目、状态和金额），点摘要进入这笔支出的详情和经办记录；只控总额的卡按学校科目展开。
   - 已入账的一笔录错了摘要或金额，点「修改」更正，金额以学校凭证为准，须写原因；原值、新值和原因记入经办记录。
   - 重复录入、录错卡的一笔点「冲销」，须写原因。冲销后不再计入已入账和可用额，这一笔仍列在明细里（划线、标「已冲销」），不会真的删除。
5. 「考核节点」：点击「新增节点」，填写节点日、要求比例和未达标的后果。至节点日，决算数应达到现行预算的该比例；系统按预测给出达标、预计不达标或未达标。
6. 「预算变更」：点击「发起预算变更」，调出填负数、调入填正数，合计为零，填写变更原因后提交。中心负责人确认后报发规办，批复后由财务岗点击「录入批复」，现行预算随即调整。
7. 「在途支出」列出该卡尚未办结的支出申请。

![经费卡详情](img/finance/10-card-detail.png)

注意：

- 明细首次录入由财务岗办理；录入后更正金额须由中心负责人办理，日常调整走预算变更。
- 下达数尚有部分未分到科目时，该部分暂不可支出。
- 横向经费的支出不得超过已到账金额；其他性质的经费卡，已到账仅作记录。
- 科目锁定的经费卡不得变更预算。
- 单据截止日后不得再提交支出；经费卡到期后按到期处理办理结清，见第十一节。

## 五、采购

涉及采购的支出申请在核对通过后，按采购路径逐阶段推进，验收贴码后方可提交学校。

1. 进入「财务 › 项目 › 采购」。页首列出采购进行中、已验收待提交学校、预计入账有风险（已过预计入账日或晚于单据截止日）和废标流标次数。
2. 在「进行中」中查看每笔采购的阶段：直采为下单、审批（约 14 天）、到货、验收贴码；集采为申报、集中采购（约 2.5 个月）、到货、验收贴码；分散采购为备案、论证、挂网竞价、合同、到货、验收贴码。

![采购](img/finance/12-procure.png)

3. 完成一个阶段后点击「推进采购」，确认后进入下一阶段。

![推进采购](img/finance/13-procure-advance.png)

4. 发生废标或流标的，点击「废标/流标」，选择类型、填写原因和预计入账顺延天数。采购退回挂网阶段，预计入账日相应顺延，记录列入「报销与入账」的退单与废标记录。
5. 验收贴码完成后，该笔转入「待提交学校」，按第六节提交学校。

注意：

- 直采单件以 5 万元为限；分摊至多张经费卡的支出共用一条采购，进度记在第一笔上，直采上限按合计金额计算。
- 支出类型规定了须采用的采购路径的，提交时自动按该路径办理。

## 六、支出申请：核对、提交学校与入账回写

每笔支出申请分申请、确认、提交学校、入账四个环节。确认环节分研究单元负责人确认、财务岗核对两步；超出预算行的，中间增加中心负责人审批。财务岗负责核对、提交学校和入账回写。

### 核对

1. 进入「课题 › 支出申请」。页面上方的标签按状态分类；轮到财务岗核对的申请出现在「待我处理」中。
2. 核对申请的事项、金额、经费卡和预算行，符合的点击「核对通过」，该笔随即占用额度，转入待提交学校。
3. 不符合的点击「退回」并填写原因。退回后该笔申请终止，申请人可查看原因，修改后重新提交。

![支出申请](img/finance/14-requests.png)

### 提交学校

1. 点击「待提交学校」标签，列出已核对、尚未把单据交学校的申请。

![待提交学校](img/finance/15-req-ready.png)

2. 单据交到学校后，在该笔右侧点击「提交学校」并确认，状态转为学校审核中。
3. 不再办理的申请可点击「释放」，额度恢复为可用，该笔申请作废。

![单据已提交学校](img/finance/16-req-send.png)

### 入账回写

1. 学校入账后，在「学校审核中」标签中找到该笔，点击「入账」。
2. 填写入账日期、入账金额和凭证号（选填），点击「入账」。决算数以学校正式入账为准。
3. 学校退回单据的，点击「退回」并填写原因，退回原因自动记入采购与报销要求，记为不可报销。

![回写学校入账](img/finance/17-req-post.png)

### 补登在途支出

用于登记已经发生、学校尚未入账的支出，例如中台启用前已办理的支出。

1. 点击页首「补登在途支出」。
2. 选择经费卡，填写事项、金额、发生日期，选择当前状态（已提交学校尚未入账，或已批准尚未提交学校），选填申请人和说明。
3. 点击「补登」。补登后计入该经费卡的在途金额，导入学校明细账时按金额对应，自动转为已入账。

![补登在途支出](img/finance/18-req-inflight.png)

注意：

- 负责人本人提交的申请无他人确认，单独列在「负责人本人提交」标签中备查。
- 年度预算下达前按经费卡提交的支出，可点击「关联预算行」关联到研究单元的预算行，关联后计入该预算行的执行，且不得超过核定数。
- 财务岗本人也可提交支出申请，提交时可在「按课题预算」和「未列入年度预算，按经费卡」之间选择；按经费卡提交的可勾选分摊至多张经费卡或多个科目。

## 七、备用金的领用与核销

备用金用于来不及办理支出申请的小额周转，先领用后报销，从年度预算行中列支。流程为：申请人选择预算行提出申请，中心负责人审批，领用，财务岗凭票核销。

1. 进入「课题 › 备用金管理」。页首列出待审批、已领用未核销、本年已核销和最长未核销天数。
2. 在「在途」标签中找到状态为「已领用，待核销」的备用金。
3. 申请人交回票据后，点击「核销」，填写实际支出金额和核销日。
4. 实际支出大于 0 的，须在「对应支出申请」中选择同一预算行上已批准的支出申请（须先在「支出申请」中登记）；全额退回的无需选择。
5. 确认核销。实际支出部分由对应的支出申请计入经费卡，未使用部分释放回预算。
6. 「全部」标签可查看历史记录，点击用途进入单笔备用金页面查看审批和核销经过。

![备用金管理](img/finance/19-petty.png)

注意：

- 备用金的批准和驳回由中心负责人办理，财务岗只办核销。
- 领用期间备用金占用该预算行，申请金额不得超过预算行的剩余额度。

## 八、报销与入账

集中办理学校侧的事项：学校退回的单据、学校审核中的单据入账、学校余额回写、到账认领与借票核销。

1. 进入「财务 › 项目 › 报销与入账」。
2. 「学校退回」：退回的单据仍占用额度。在该笔右侧点击「变更经费卡」改至其他经费卡或科目重新送审，或点击「释放」。目标经费卡须允许该类支出、可用额度充足，且预计入账日不晚于其单据截止日。
3. 「学校审核中」：逐笔点击「入账」，或使用批量入账（见下）。

![报销与入账](img/finance/20-school.png)

### 批量入账

1. 在「学校审核中」点击「批量入账」。
2. 将学校入账清单的「金额、日期、凭证号」逐行粘贴到文本框，点击「按金额匹配」，系统自动勾选金额唯一对上的单据并填入日期和凭证号；对不上或有重复金额的，手工勾选并填写。
3. 核对已勾选的笔数和入账合计，点击「入账 N 笔」。整批一起入账，有一行不符则整批不入。

![批量入账](img/finance/21-school-batch.png)

### 学校余额对账

1. 「学校余额对账」逐张列出本系统可用与学校余额、冻结、可用的差额。
2. 对照学校财务系统，点击「回写」，填写余额、冻结和可用（可用留空时按余额减冻结计算）。
3. 学校可用与本系统可用不一致时，通常是有单据未登记或入账未回写，应逐笔查明。

![回写学校余额](img/finance/22-school-balance.png)

### 学校侧记录

1. 点击页首「登记」，选择经费卡和类型（到账、认领、预借票、核销、下达、冻结、回收），填写日期和金额。
2. 需后续办理的（例如到账后认领、借票后待款项到账核销）填写待办；办结后在「到账认领与借票核销」中点击「标记已办」。
3. 学校中途回收过经费的，登记一笔「回收」，经费卡按明细核对学校余额时即予扣除。

## 九、明细账校准

学校财务系统导出的项目收支明细账用来校准经费卡的下达数、已入账和学校余额。上传在各经费卡的页面办理，明细账校准页列出每张卡上次校准的时间。

1. 进入「财务 › 项目 › 明细账校准」，页首说明超过 30 天未校准或从未校准的在用经费卡张数，表中标「从未校准」或「N 天前」。

![明细账校准](img/finance/23-ledger.png)

2. 点击该卡右侧「上传明细账」进入经费卡页面，在「导入明细账」中选择学校系统导出的 .xls 或 CSV 文件。
3. 系统列出文件所属项目、年初余额、收入、支出和期末余额，并说明中台已有和将新增的笔数。先核对文件所属项目与本经费卡一致。
4. 按需勾选：该经费卡只控总额；保存收入明细并据此更新下达数和已到账（年初余额记为上年结转）；将学校余额更新为期末余额。
5. 核对将新增的已入账支出，点击「确认导入」。与在途支出申请金额对应的，自动转为已入账。

![导入明细账](img/finance/11-card-ledger.png)

注意：

- 文件仅在浏览器中读取，中台不连接学校系统，不保存学校系统的密码。
- 已导入过的行不会重复写入。红字（负数）行不导入，须在中台手工处理。
- 暂不支持 .xlsx，请使用学校系统导出的 .xls，或另存为 CSV。
- 导入后经费卡上有不在学校明细账中的已入账支出的，页面会提示，确属重复或旧记录的可点击作废，作废后不再计入已入账，记录保留。

## 十、人员经费

人员经费按人、按月排布到经费卡，每月按排布生成发放表，学校入账后回写。

1. 进入「财务 › 项目 › 人员经费」。「人员 × 月份」每格为当月发放额及列支的经费卡；红格表示发放日（当月 20 日）不在该经费卡有效期内，该笔无法发放，需变更经费卡。
2. 「检查」列出列支于已回收、已结题或未下达经费卡的人月数，以及本月尚未列入发放表的排布。

![人员经费](img/finance/24-staff.png)

3. 排布：点击右上角「排布」，选择人员、发放类型、起止月份、经费卡，填写每月金额，点击「保存排布」。金额留空表示撤销该段排布。

![排布人员费](img/finance/25-staff-plan.png)

4. 生成发放表：在「发放表」中点击「生成发放表」，选择月份。系统按发放类型和经费卡分表，仅纳入发放日在经费卡有效期内的排布。
5. 学校入账后，在发放表右侧点击「入账」，填写学校入账日期，计入决算数。
6. 排布时从人员档案中选人；名单里没有的新人，请人事先在「人员档案」中登记，姓名有误的也在那里修改。发放类型在页面下方办理，决定该笔款项计入的科目，可设每人每月上限。

注意：

- 已列入发放表的月份不得修改排布。
- 整段排布变更到其他经费卡由中心负责人办理。

## 十一、经费结清

经费卡到期后办理结清：按科目固定预算、决算和结余，结余按到期处理回收或结转。

1. 进入「财务 › 项目 › 经费结清」。「年度汇总」按年度列出各经费卡的现行预算、当年决算、累计决算、执行率、承诺和可用。年度决算按学校入账日归属年度。
2. 「待结清经费卡」按结清日列出已设结清日的在用经费卡，「结清前待办」列出须先办完的事项，如未结的支出、办理中的调整、未入账的人员费。
3. 财务岗据此清理：在途支出办理入账或释放，人员费发放表入账，预算变更办结。
4. 待办清零且到结清日后显示「可结清」，由中心负责人点击「结清」办理。
5. 尚未设结清日的经费卡列在表下方，须先在经费卡页面填写结清日。

![经费结清](img/finance/26-settle.png)

注意：

- 结清后该经费卡不得再提交支出和调整。结转的结余按科目带入该项目下一张同卡号经费卡；到期回收的结余记为回收数，回到项目的额度剩余。
- 结清后学校仍有出账的，可由中心负责人在「已结清」中点击「改回未结清」，补登在途支出或导入明细账后重新结清。已结转的经费卡不能改回。

## 十二、年度预算

年度预算按「测算总预算 › 直接确定金额的课题 › 编档次 › 批准方案 › 立项与延续申请 › 评定 › 下达执行 › 年度决算」进行。财务岗负责启动年度、测算总预算、编方案、审核下达和复盘；批准方案、确认评定完成和年度决算由中心负责人办理；评定结果由中心助理按联席会议决定录入。

### 启动年度

1. 进入「财务 › 年度预算 › 预算编制」（或「预算参数」），点击「启动新年度预算」。
2. 填写年度和申报截止日，确认。截止日在方案编制阶段可点击「修改截止日」调整。

![启动新年度预算](img/finance/27-budget-open.png)

### 测算总预算与编制档次方案

1. 进入「财务 › 年度预算 › 总预算与档次」，用页首年度链接切换到该年度。
2. 「测算依据」逐个列出在执行的项目及其额度剩余、在用经费卡预计结余和到期处理。在每个项目右侧点击「填写」，按预计明年可用于中心的数填写计入金额，不计入的留空。各项目计入金额合计即年度总预算。

![总预算与档次](img/finance/28-plan.png)

![计入年度总预算](img/finance/29-plan-source.png)

3. 「直接确定金额的课题」：中心公共开支这样的课题金额由方案直接确定，从总预算中先行扣除，不参加档次评定。点击「直接确定课题的金额」，选择已有课题或填写名称新立课题，填写金额。
4. 「档次」：点击「新增档次」，填写档次名称、每个课题的金额、名额，选填劳务类比例上限和其他类别的比例上限。各档「金额 × 名额」合计不得超过扣除直接确定金额后可按档次分配的数。

![新增档次](img/finance/30-plan-tier.png)

5. 方案编好后提请中心负责人批准。批准后向各课题公布档次，课题负责人在「立项与延续申请」中选档并在「预算编制」中提交明细。批准后如需修改，须中心负责人先撤回批准；已有课题申请档次的不得撤回。

### 申报与评定期间的工作

1. 在「预算编制」中查看本阶段说明和各课题明细的提交情况。「经费来源核对」核对两项：到期回收的经费卡须在节点前使用完毕；学校年度经费 4 月批复，1–3 月的支出只能由可结转的经费卡列支。
2. 课题提交的明细有误的，在该课题下点击「退回重新填报」并填写原因。
3. 评定由联席会议决定，中心助理在「总预算与档次」的「评定」中录入；全部录入后由中心负责人确认「评定完成，转入下达」。此后档次金额即课题的年度上限，已提交的明细即核定的预算行，年度进入「评定完成，待下达到经费卡」。

![预算编制（评定完成待下达）](img/finance/31-budget.png)

### 下达至经费卡

评定完成后，各行核定数须分配到经费卡的学校科目上才能支出。可以按课题逐个审核下达，也可以全部分配完毕后整个年度一并下达。

1. 在「预算编制」下部的「下达至经费卡」查看核定数合计、已分配和尚未分配。

![下达至经费卡与按课题审核下达](img/finance/32-issue.png)

2. 逐行分配：经费卡由财务岗决定，系统只做推荐。在「各预算行分配情况」中点击某行的「分配」（已分配的为「修改」），弹出框列出可用的经费卡和学校科目，每张卡后面写明尚可分配的数额和这张卡已答复可报销的支出类型。尚未分配的行已按系统推荐预填（标有【推荐】），推荐只按到期回收优先和可用余额计算，不看能否列支：请对照每张卡的可报销答复，改成实际要用的经费卡，合计不得超过核定数，不使用的留空，保存。

![逐行分配](img/finance/33-alloc.png)

3. 按课题审核下达：在「按课题审核下达」中，已提交预算的课题显示「待审核」。课题的各行都分配完毕后，右侧出现「审核通过并下达」（未分配完的提示先逐行分配）；点击后选填审核意见并确认，该课题及其研究单元随即可以提交支出申请，课题负责人和研究单元成员会收到通知。系统不会在下达时替财务岗分配经费卡。

![审核通过并下达](img/finance/34-topic-issue.png)

4. 撤销下达：已按课题下达、尚无任何支出和在办申请的课题，可点击「撤销下达」，收回分配到经费卡的数额。年度整体下达后不能单独撤销。
5. 年度整体下达：全部预算行分配完毕后，「下达」按钮变为可用，点击确认。下达后各研究单元按预算提交支出申请。
6. 「到期回收的经费卡须使用完毕」列出年内到期回收的经费卡，分配后仍未被预算覆盖的可用额即将被收回的缺口，应追加预算安排支出或提前向学校申请调整。

注意：

- 预算科目尚未对应学校科目，或没有有效期覆盖该年度的经费卡时，分配框中没有可选项，也没有推荐。先在「预算参数」中设置科目对应，并在「项目管理」中开出经费卡。
- 经费卡对应科目可用余额不够时，推荐会标明还差多少，须另选经费卡或调整核定数。
- 所选经费卡对这一行的支出类型还没有可报销答复的，成员提交支出时会被拦下：先向学校财务确认，并在「采购与报销要求」中记录答复。
- 已下达年度在复盘时调增核定数的行，须在此补充下达；调减部分系统自动收回。
- 中心负责人特批档次的课题，可在下达前补填明细，提交即核定，下达时与其他课题一并分到经费卡上。

### 核定后补填与调整课题预算

年度评定完成、整体下达之前，财务岗在「预算编制」各课题的预算卡片里办理：

1. 公共课题不评档次，申报截止后由财务岗补填：在该公共课题下点击「新增预算行」或「整表导入」，填好后点击「提交」，提交即按明细核定；下达前可以撤回修改。
2. 已提交、已核定但尚未下达的课题，在预算行右侧点击「调整核定数」，填写新的核定数和调整原因后保存。调整后课题连同研究单元的核定数合计不得超过档次金额；调减到低于已分配到经费卡的数额时，多出的分配自动收回。调整记入预算调剂记录，课题负责人可见。
3. 已按课题下达的课题不能直接调整：先在「按课题审核下达」中点击「撤销下达」（课题尚无支出时可以撤销），调整后再审核下达。年度整体下达之后的调整由中心负责人在「年度决算」中办理。

### 早期年度的报学校流程

此前按旧流程编制的年度，在汇总报批阶段由财务岗逐行调整申请数、中心负责人批准申请数；报学校后由财务岗点击「登记已报学校」，学校批复后点击「录入学校批复数」，再按联席会议决定逐行填写核定数，由中心负责人确定年度总预算。「预算参数」的年度表中保留各年度的报学校和学校批复日期。新启动的年度不再经过这几步。

## 十三、预算控制

各课题的年度上限由中心负责人按档设定，课题连同下属研究单元的预算合计不得超过上限。各课题上限合计低于年度总预算的部分为机动，用于年中提高上限和超预算支出。

1. 进入「财务 › 年度预算 › 预算控制」，用年度按钮切换年度。
2. 页首列出年度总预算、各课题上限合计、机动和已编入预算。
3. 「各课题」逐个列出上限、已编入预算和剩余可排；有提高上限申请的，列在「待审批的提高上限申请」中，由中心负责人同意或不同意。

![预算控制](img/finance/35-caps.png)

注意：

- 上限按档设定：1 千、5 千、2 万、5 万、20 万、50 万，50 万以上按实际数填写。研究单元不单独设上限，计入所属课题；中心公共开支不设上限。
- 设定和修改上限由中心负责人办理，财务岗查看。

## 十四、年度决算与季度复盘

年度预算下达后每三个月按研究单元复盘一次，年末办理年度决算，未用完的预算不结转。

1. 进入「财务 › 年度预算 › 年度决算」，选择年度。页首列出核定数合计、已用（含在途）、已入账和未使用。
2. 「按研究单元复盘」比较截至本期末的计划支出与学校实际入账，入账不足计划 70% 的标为落后。执行期内点击「填写复盘」，选择预算期，写明偏差原因及下一期措施。
3. 点击「明细」查看各预算行每期计划与入账、核定数、剩余和对应经费卡，以及复盘、调剂和核定数调整记录。
4. 预算调剂全年累计超过研究单元年度预算 10% 的，列在「待审批的预算调剂」中，由中心负责人审批。
5. 「年度决算」表列出各研究单元的核定数、决算数、在途、未用和执行率。年度结束且全部支出申请审批完毕后，由中心负责人办理年度决算。
6. 「年末盘点差异」列出资产盘点中与账面不一致的项，决算前须有说明。

![年度决算](img/finance/36-review.png)

注意：

- 决算后该年度预算不可再支出，未用完部分作废；年末尚未入账的在途支出照常在经费卡上办结。
- 核定数的调整由中心负责人在预算行上办理，调减不得低于已用。

## 十五、预算参数

年度预算截止日、预算科目及其对应的学校科目、学校系统文件导入在此办理。

1. 进入「财务 › 年度预算 › 预算参数」。「年度预算」表列出各年度当前环节、申报截止日、报学校和学校批复日期，方案编制中的年度可「修改截止日」。
2. 「预算科目」是中心内部口径，研究单元申报时按此填报。点击「新增科目」或「修改」维护代码、名称、顺序、是否劳务类和是否在用。

![预算参数](img/finance/37-desk.png)

3. 点击某科目的「对应学校科目」，勾选该预算科目可列支的学校科目。不同经费卡的科目模板不同，各模板中可用的科目均须勾选。未对应的科目下达时不能自动分配。

![对应学校科目](img/finance/38-desk-map.png)

4. 「预算兑换实际币」：每季度开始时点「公布本季度」，填本季度全中心可兑换总额（下季度 API 充值中能经学校报销的金额）和三个兑换比例（1 元预算兑多少实际币、1 实际币兑多少元 API 额度、1 卡时多少实际币），点「公布」。卡时标价随之更新。本季度已有兑换的，比例不能再改，总额只能追加。表下列出本季度各课题的兑换记录。
   - 财务岗按计划直接充值 API，不等兑换；本季度兑换的预算用于下季度充值的报销，没兑满的部分由谢倩倩老师兜底。
   - 「算力与模型接口」科目不走支出申请；API 充值在支出申请里只由财务岗办理。

4. 「代币参数」列出名义币、实际币和卡时的现行参数，由中心负责人修改，财务岗查看。代币不是钱，不与经费卡和学校账目发生关系。
5. 「从学校系统导入」：在学校财务系统导出后上传、粘贴，或对照学校系统逐项填写，可批量更新各经费卡的学校余额或回写入账。系统先列出与现有数据的差异，勾选确认后写入。

## 十六、采购与报销要求

记录学校对某张经费卡某类支出明确答复过的限制。经费卡的报销科目和金额在各经费卡上设置，支出由财务岗核对、分配到经费卡时把关；没有记录的支出类型可以正常提交。明确不能列支的拦截；学校退过单的标为有争议，改挂经费卡时不能改到这类卡上。

1. 进入「系统 › 采购与报销要求」。「报销限制」只列有答复的经费卡和支出类型，展开「按经费卡查看」可见可报销、有条件报销、不可报销或有争议，有条件的附说明。
2. 咨询财务处或发规办后，点击「新增答复记录」，选择经费卡、支出类型和答复，填写答复日期、答复人或部门；有条件报销和不可报销的须填写条件或说明，保存。
3. 「支出类型」中可新增和修改类型，并指定须采用的采购路径（直采、集采、分散采购）。类型不可删除，更名同步到已有记录。勾选「仅由财务岗办理」的类型（如 API 充值）课题不能从预算行提交：接口账户由财务岗从经费卡付款充值，到账后在资源页入库为额度，课题使用额度走资源申领。
4. 「答复记录」按经费卡筛选历次答复；来自学校退单的标明「来自学校退单」。

注意：

- 同一经费卡同一类支出前后答复相反的，标为有争议。
- 学校退单的原因自动记为不可报销。

## 十七、在途事项

集中查看所有尚未办结的支出申请、备用金和资源申请，以及每笔当前等待的对象。本页只供查看，不办理业务。

1. 点击导航「在途事项」。页首列出在途事项总数、紧急和加急、等待超过 7 天和学校退回的数量。
2. 表中按紧急程度和提交先后排序，「当前等待」一栏说明等谁办理，如研究单元负责人确认、财务岗核对、中心负责人批准、财务岗提交单据至学校、学校入账。
3. 需办理的，点击右侧「办理 →」进入对应页面。
