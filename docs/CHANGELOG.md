# 科研财务中台更新日志

> 规范：每次发布记录版本、日期、问题背景、变更内容与验证结果；未完成事项不得写入已完成版本。

## 1.5.0 · 2026-10-04

### 资源中台总览

- 新增 Finance「资源中台总览」只读入口，按预算、资金与资源池、财务安全、财务执行、账目维护、资产与使用权六层展示现有数据。
- 复用现有 Finance Dashboard、Workspace、API 资源池接口，不新增生产账务实体，不覆盖历史记录，不改变原有审批和入账流程。
- 项目执行表同时展示预算、已支出、承诺、执行率、风险和预计结余；API 资源池明确区分采购额、已分配额和平台余额。
- 新页面支持桌面、窄屏和移动端布局，刷新失败时保留明确错误提示。

### 验证

- 前端 `npm run build` 通过。
- Worker `npm run build` 通过；本次未修改 Worker。
- 未修改飞书历史数据、权限、用户 ID、项目预算或既有业务接口。

## 1.4.0 — 2026-10-01

### Excel 支出导入审计闭环

- 新增导入批次记录，保存文件标识、操作人、时间、总行数、成功数、失败数和最终状态。
- 导入确认改为服务端整批预校验；错误按 Excel 行号展示，区分预校验失败和正式写入失败。
- 批次支出在批次完成前不参与预算、支出和项目统计；正式写入失败时保留审计记录并支持安全重试，避免部分入账污染正式账本。
- 实际支出页面增加批次历史、错误明细和导入结果查看入口，保留原有手工录入和 Excel 预览流程。

### 验证与发布

- 前端与 Worker 构建通过；新增导入校验纯逻辑测试通过。
- 未修改历史预算、支出、飞书用户、权限或既有实体语义。

## 1.3.1 — 2026-09-30

### 经费项目首轮重构

- 经费项目页增加项目名称/项目号搜索、经费类型筛选、状态筛选和分页。
- 列表补充真实总额度、已支出、可用额度、执行率、收回时间和风险状态。
- 支持展开项目详情，查看真实预算分类、实际支出和月度支出聚合；无数据时明确显示空状态。
- 补充页面加载、错误、重试和刷新反馈，保留原有项目新增与编辑流程。
- Excel 支出导入改为“全量预校验后再写入”，补充主体、日期、金额、项目分摊合计校验，降低部分批次入账风险。

### 验证与发布

- 前端 `npm run build`、`npm run build:pages` 通过。
- Worker `npm run build` 通过，Worker 业务代码未修改。
- Pages 已发布至 `finance-portal` 项目，正式入口和国内备用入口返回新构建版本；发布仓库提交 `37e8f36`。
- 未修改飞书记录、历史预算、支出或权限数据。

## 1.2.0 — 2026-08-25

### 晨星预算与币种

- 晨星预算独立于 API 采购预算，支持 Excel 解析、附件索引和 Finance 审核。
- Leader 可在审批/归集前撤回，历史记录保留，Finance 与申请人均可查看状态。
- 增加幂等提交、超时恢复、人民币校验和基于 ECB 参考汇率的 USD/CNY 估算工具。
- Finance 可批次查看完整明细，整批通过或整批打回，打回原因同步申请端。

### 权限与业务规则

- 落地 Finance/Leader 数据范围控制、密码哈希和管理员重设密码。
- 支持纵向、财政、横向项目、到期时间、预算进度及劳务费 30% 校验。
- 支持五类支出及可扩展二级分类、项目优先级和同级轮换分配。
- API 申请与采购资源池解耦，接入 GreatRouter 模型目录、额度分发和防超发校验。
